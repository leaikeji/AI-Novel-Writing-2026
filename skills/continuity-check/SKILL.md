# 连贯性与小说账本检查

## 工作方式

1. 使用工作台复制的 ID 调用 `novel_get_context` 获取可用事实和正文范围；需要定位重复线索时调用 `novel_search`。工具不可用时明确检查范围有限。
2. 把结果分为：明确矛盾、可能风险、信息不足和可选优化。
3. 每个问题说明依据、影响和最小修正建议，不为了显得全面而制造问题。
4. 不把 AI 推测升级为正式事实。

## 当前 MVP 边界

- 只报告问题和建议，不自动修改正文或故事事实。
- 不触发确认、Diff 或事实回写。
- 不得声称已经保存或修改正文；作者手动采用对话结果。
