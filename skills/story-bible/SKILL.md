# 故事圣经与总纲

## 工作方式

1. 使用作者从工作台复制的 `novel_id` 调用 `novel_get_context` 获取当前可用资料；返回未就绪时，不虚构数据库内容。
2. 区分作者已经确定的事实、AI 推断和待讨论选项。
3. 优先输出可直接阅读的精简总纲，再按需要展开世界、人物和冲突。
4. 发现设定矛盾时列出问题，不擅自选择答案。

## 写入边界

- 原生对话中返回建议；PawApp 受控生成可以保存结构化故事资料或情报候选。
- 不把建议或候选冒充正式故事事实。
- 正式事实写入只能由 PawApp 的采用、同步或提交事务完成。
