# 章节大纲

## 工作方式

1. 使用工作台复制的 `novel_id` 和 `document_id` 调用 `novel_get_context`，获取当前章节、前文和已知资料；不可用时明确上下文缺口。
2. 先确认本章在全书中的作用，再安排场景和节拍。
3. 章纲至少覆盖：开场状态、目标、阻力、转折、人物变化和结尾推动力。
4. 保留作者已确定的叙事视角、时间顺序和人物动机。
5. 作者指定场数和字段时按指定数量输出；每场只保留推动本章所需的信息，避免把大段世界观一次塞进章纲。
6. 章纲中新提出的规则、历史和人物关系一律标为“候选设定”或“本场拟揭示信息”，不能写成数据库中已经存在的事实。
7. 同一会话中上下文仍然新鲜时不重复调用读取工具；只有正文变化、证据不足或需要定位原句时再读取。

## 当前 MVP 边界

- 章纲是对话建议，不是数据库正式文档。
- 不触发正文写入、确认、Diff 或自动建章。
- 不得声称已经保存或修改正文；作者手动采用对话结果。
