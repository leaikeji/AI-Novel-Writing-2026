# 人物声音页重复控件与提示审计

日期：2026-08-31

结论：当前页面存在 4 组应删除或合并的重复入口、3 组可精简提示。建议保留两个不同的一键能力，不把“匹配官方音色”和“生成全新专属音色”合并。

## 审计范围

- 页面：正式人物卡 → 声音。
- 目标：检查重复功能按钮、重复状态表达和重复说明文字。
- 方式：长期 PawApp 只读检查；没有生成、试听、绑定、保存或删除数据。

## 流程与结论

1. **默认声音页：需要精简**
   - 证据：`01-default.png`。
   - 每个官方音色的单选框与“用于许棠”按钮调用同一个应用动作，形成两个键盘焦点和两个等价入口。
   - 当前音色行同时出现选中单选框、`当前使用`标签和禁用的`当前使用`按钮，状态表达重复。
   - 音色库标题说明与常驻灰色提示都在说明“可直接使用、试听非前置”，保留一处即可。
   - `18 项`、`中文（6）`和`当前显示 6 项`在无搜索条件时重复计数；建议只在搜索生效时显示过滤后数量。
2. **高级私人音色区：明显重复**
   - 证据：`02-advanced.png`。
   - “官方音色请在上方使用”在区块说明、加载状态和音色来源说明中出现三次；只保留区块说明。
   - `2. 选择音色来源`与内层`音色来源`是重复标题；保留步骤标题即可。
3. **声音页底部：需要去除无效外层操作**
   - 证据：`03-footer.png`。
   - 声音组件已有`保存人物声音`，外层人物卡仍显示禁用的`撤销修改`和`保存人物卡`，容易让作者误以为声音需要再保存一次。
   - 声音标签页应隐藏外层撤销和保存，仅保留关闭；顶部关闭 X 与底部关闭属于标准双入口，可以保留。

## 建议保留的相似入口

- `为许棠生成并使用专属音色`：真正生成一条新音色。
- `根据人物卡匹配并使用官方音色`：只从 18 个官方音色中匹配。
- `试听`、`详情`、`使用`：任务不同，不属于重复。
- 搜索框标签与占位提示：一个说明字段用途，一个说明可搜索范围，不属于重复。

## 推荐收敛方式

- 官方音色行采用唯一的选项式动作：保留单选框并让整行可点击，移除`用于许棠`按钮；当前行只保留选中态和一个`当前使用`标签。
- 空闲时不显示操作状态条，仅在应用中、成功、失败或冲突时显示动态状态。
- 高级私人音色区只保留一次去向说明和一级步骤标题。
- 声音标签页 footer 只保留`关闭`，所有声音写入由声音组件自己的按钮负责。
