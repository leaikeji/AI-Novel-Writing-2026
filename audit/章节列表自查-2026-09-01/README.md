## 发现

### P1：返回章节列表后可能显示过期版本状态

- `saveNow()` 更新 `document`，不更新承载列表数据的 `novel.tree`。
- `backToProject()` 只切换页面和 URL，没有调用 `refreshNovel()`。
- 结果：章节从“已建检查点”变成“工作稿已保存”后，立即返回列表仍可能看到旧标签，造成错误的版本判断。

### P2：首次排序会改变当前分卷

- 未显式选择分卷时，当前详情使用 `orderedVolumes[0]` 作为回退。
- 排序改变 `orderedVolumes[0]`，因此详情内容跟着跳转。
- 期望：排序只改变左侧顺序，保持当前分卷；首次加载时应把默认分卷写入显式选择状态。

### P2：表格与操作菜单的无障碍语义不足

- 表头被 `aria-hidden="true"` 隐藏，行又使用普通 `div`，读屏无法建立“章节／版本状态／更新时间”的列关联。
- 移动菜单按钮缺少 `aria-haspopup` 和 `aria-expanded`；自动化键盘 Escape 未关闭弹层。
- 11–12px 的状态与元数据文字对比度不足 4.5:1：检查点 4.39:1、工作稿 3.45:1、空白草稿 3.92:1、表头 3.33:1、更新时间 3.34:1。
