## 发现

### P1-1：折叠高级设置没有真正隔离内部交互内容

- `<details open=false>` 的外框只有约 65px 高，但 `.anw-character-voice-advanced__body` 被作者样式强制为 `display:grid`，实测仍形成约 1948px 的布局盒。
- 折叠时，语义快照仍枚举其中的 select、input、button 和 option；组件也已经完成私人音色与人物声音数据加载。
- 风险：键盘／辅助技术可能进入肉眼不可见的控件，折叠也没有达到延迟加载和降低后台请求的目标。
- 建议：关闭态显式 `display:none` 或按 `open` 懒挂载内容，并补“关闭态无子控件焦点／语义节点”的自动化和真实键盘复验。

### P1-2：权威 README 仍描述旧六音色产品范围

- 根 `README.md` 与 `docs/README.md` 仍写“正式产品只包含／展示 6 个中文 preset、18 项只作底层兼容”，并引用旧 `0024` 阶段。
- 当前事实已是 18 音色直用、`0035`、VoiceGenerator 产品闭环；计划 35/40 与运行态均证明旧说明失效。
- 风险：下一轮维护、安装或验收会按错误范围决策。
- 建议：只更新当前事实摘要和索引，不改写历史计划与原始验收证据。

### P2-1：窄屏官方音色列表仍然过长

- 390×844 下每个音色把“试听／使用／详情”排成三行，6 个中文音色使正文达到 2246px。
- 当前没有遮挡或横向滚动，功能可用；但作者需要较长滚动才能到高级设置。
- 建议：保持 44px 触控高度的前提下，把试听和使用改为两列，详情单独一行，或让整行承担选择动作。

### P2-2：单选圆点本体只有 18×18px

- 每行同时提供了大尺寸“用于许棠”按钮，因此存在等价可用入口，不构成阻断。
- 但单选圆点本身的触控面积仍偏小；建议用 44px 包裹标签扩大热区，保持可见圆点为 18px。
