## 范围与方法

依次覆盖建书、设定/大纲、人物/关系/故事线/伏笔、建章、正文、选区修改、审稿、同步进展、账本核对、后续章节承接、保存/历史恢复，以及私有库/向量检索在写作中的使用。先记录每一步，再形成保留/合并/可选/删除/补足建议。截图是体验证据，API结果是运行事实，源码只用来解释原因。单次样书观察不宣称长期写作能力增益或严格因果证明。

本任务不并行：连续写作依赖同一小说状态与浏览器会话，主代理串行体验并记录；不派发旧施工任务。

用户补充重点：逐步记录会固化创作内容的硬编码，包括代码提示词、模板默认剧情、强制结构/钩子、固定数值与自动重写。区分作者明确约束、可编辑建议、不可修改内容约束、技术安全限制；每项标注位置、触发条件、实际结果与待验证影响。本轮先审计，不直接删改。

新增操作边界：用户禁止在右侧QwenPaw助手对话；全部生成只从产品内置对话框与按钮触发。此前曾因定位过宽把本轮创意误填入未发送的助手输入框，未点击发送；此误操作不计作产品生成调用或产品缺陷。后续定位精确限定在产品弹窗。
