# 计划 61：阿里云签名音频 HTTPS 兼容修复

- 日期：2026-09-08
- 状态：代码、测试、打包和长期热安装 PASS；真实计费复测等待作者操作

## 原因

阿里云 Qwen-Audio-TTS 非流式 HTTP 接口的成功响应可能返回 `http://*.oss-cn-beijing.aliyuncs.com/...` 签名音频地址。原适配器只接受 HTTPS 下载地址，因此会在合成响应成功后拒绝音频下载，并统一记录为 `TTS_PROVIDER_RESPONSE_INVALID`。

官方响应格式：<https://help.aliyun.com/zh/model-studio/cosyvoice-tts-http-api>

## 修复

- 仅对无显式端口、无用户信息、无 fragment，且主机名后缀为 `.oss-cn-beijing.aliyuncs.com` 的 HTTP 音频结果地址升级为 HTTPS。
- 请求路径和签名查询参数保持不变。
- 任意其他 HTTP 地址继续拒绝。
- HTTPS 地址、DNS 公网复核、SSRF 防护、响应大小限制和禁止重定向策略保持不变。
