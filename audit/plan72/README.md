## UX与可访问性风险

- 原标签页的恢复ticket存于浏览器sessionStorage；换浏览器或新标签页不会展示同一动作的特殊按钮，而是依靠服务端单活409接管。这是安全隔离设计，但用户可能误以为不同标签页“状态不同”。当前状态卡文案已说明重复点击不会新建任务，风险可接受。
- 本轮应用内隔离浏览器没有作者原标签页ticket，无法在正式页面视觉上重现“确认重新生成”特殊态；因此不把普通章节页截图当作该特殊态的证据。
