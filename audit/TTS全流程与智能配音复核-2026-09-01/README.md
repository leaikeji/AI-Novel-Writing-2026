### P1：更智能的配音

1. **整本选角优化**：先计算所有主要人物的声音距离，再联合分配官方音色，避免许棠与方若岚同时落到 `CN 深夜电台`；作者仍可一键覆盖。
2. **场景表达真正落地**：当前已经识别 emotion、whisper、shout、inner monologue，但实际 Sidecar 请求只携带文本、音色、seed 和 decode 参数。应先冻结“表达决策 → 模型支持能力”的适配契约，再让可验证的表达变化进入合成与 cache fingerprint；不把 Nano 采样参数伪装成精确情绪／语速／音高旋钮。
3. **章节配音预检**：生成前列出未识别说话人、同场声音过近、语言不匹配和可能误判的独白，一次点击自动修复可确定项。
4. **轻量偏好学习**：作者只需点“更年轻／更沉稳／更明亮／更慢一点”；官方匹配更新人物偏好，专属音色则更新 VoiceGenerator instruction 并生成新不可变版本，不直接改写已冻结 Edition。
5. **重要性分级**：旁白和主角默认建议专属音色；普通配角先智能匹配官方音色，避免无必要地启动约四分钟的 VoiceGenerator 重任务。
