## 未收口问题与原因定位

### P1：全部事实筛选值白字白底

`frontend/src/characters/styles.ts` 为筛选 `select` 固定了白色背景，却没有固定文字颜色。真实 QwenPaw 深色宿主的全局样式将 `select` 文字继承为白色，导致已选的“全部”不可见。浏览器计算样式为 `color: rgb(255, 255, 255)`、`background: rgb(255, 255, 255)`。

### P1：来源查看器标题和关闭按钮白字白底

来源查看器固定白色背景，但标题和关闭按钮没有局部颜色重置，受到宿主全局 `h3`／`button` 深色主题规则影响。计算样式中标题为 `rgba(255, 255, 255, 0.85)`，关闭按钮为 `rgb(255, 255, 255)`；副标题和正文仍可见。

### P1：来源查看器焦点未进入

来源查看器声明为 `role="dialog" aria-modal="true"`，但打开后 `document.activeElement` 为 `BODY`。人物卡主对话框已有焦点进入、焦点环和 Esc 处理，嵌套来源查看器没有等价的焦点进入／关闭后焦点恢复；键盘用户可能无法立即定位到关闭按钮或内容。

### Release blocker：长期 18088 未安装候选

长期页面仍是旧栏目和旧事实墙；Workspace V2 显式协商也未可用。因此源码候选通过不等于用户正在使用的环境已修复。
