## 检查方式与边界

- 先在 Codex 内置浏览器读取正式作品页面，保存 01–05 原始截图，再审查实际可见控件；没有保存、生成、清理、改正文或绑定音色。
- 新版使用实际前端源码在独立 Vite `18177` 预览，读取正式公开 GET 接口。代理在转发前拒绝所有非 GET／HEAD 请求，避免预览动作写入作品。
- 预览宿主是临时的公开接口适配，不是 QwenPaw 正式安装。临时目录 `/private/tmp/reading77-preview.W05QqO`；React 依赖只在此预览目录，未加入产品依赖。预览范围列表仅提供当前章节，未装配整书生成入口。
- 桌面 viewport 覆盖设为 1600×1000；记录的实际页面 clientWidth 为 1569。另将内容容器限制至 900 像素模拟宿主面板挤压，实际内容 clientWidth／scrollWidth 均为 885，没有水平溢出。不做手机验收。

## 实际交互证据

- 播放倍速用键盘从 1.50 调至 1.55，切到旁白音色再返回，仍为 1.55 且显示未保存；没有发送保存。
- 私人音色名称输入“沉静的叙述者”，切到规则后再返回，输入仍在。
- 识别规则选择“每次都由作者复核”，切到发音词典再返回，DOM 读取 checked=true；另一项 checked=false。两区不同时显示，切换焦点移入当前分区。
- 六个导航入口可达，章节例外原生展开控件可打开；旧入口映射和稳定挂载／隐藏由测试覆盖。
- 浏览器错误日志检查返回空数组。预览保存请求被禁止；未以模型或网络失败修改正式正文和音频。
