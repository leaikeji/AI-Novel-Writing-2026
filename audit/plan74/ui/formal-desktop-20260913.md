# 计划74正式桌面验收

日期：2026-09-13。环境：正式QwenPaw 2.2.0，桌面Web，PawApp `0.4.0`。结论：`PASS`。

## 实际操作路径

1. 从创作中心进入“私有库”，切换当前作品为《缺氧：末日地下世界》。页面显示四个分类、搜索、保存范围和启用状态筛选。
2. 用词列表显示`本书用词`（本书专用、已启用、v4）、`灾后设施抢修词（本书）`（本书专用、已启用、v2）和通用`灾后设施抢修词`（未启用、v4）。
3. 打开`本书用词`，详情只显示推荐词“管钳”；版本历史保留v1—v4，临时禁用词已通过补偿版本在当前版本中移除。
4. 打开`灾后设施抢修词（本书）`，详情显示“封堵”及本书专属说明；再打开通用包，确认仍为原说明且未在甲书启用。
5. 在章节《签下这栋破楼》中执行“检查用词”，保存按钮提示“用词检查完成：未发现慎用或禁用表达”。
6. 选中正文末句后执行“润色”和“自定义修改”，均进入有键盘按钮的Diff审阅；0处修改时明确显示“未发现需要修改的差异”，退出审阅后正文与4380字计数保持。
7. 完整卸载并公开热装后刷新页面；创作中心、私有库入口、作品切换、资产列表、启用状态和版本历史均恢复。

## 桌面可用性结论

- 首次收藏只需选区、动作和保存范围；高级元数据不阻塞。
- 通用资料与本书副本在同一页可辨识，不增加第五类；“已启用／未启用”“本书专用／通用库”和版本号均可见。
- 归档与历史恢复使用准确文案，未提供永久删除快捷动作。
- 章节工具保留保存、朗读、历史、Diff和助手面板；私有库新增入口没有替换QwenPaw原生助手。
- 鼠标和键盘均能完成作品切换、退出审阅及主要按钮操作；本任务未加入手机或触控验收。

正式页面未保存静态截图到仓库；本记录基于实际可访问性树、服务端回执和数据库状态交叉核对，不把自动化组件测试伪装为桌面验收。
