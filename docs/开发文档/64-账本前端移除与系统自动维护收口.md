# 账本前端移除与系统自动维护收口

状态：2026-09-10 用户已明确授权本次范围及共享 QwenPaw 安装；代码、自动化、安装和本轮运行验收完成。长期 `18088` 的 QwenPaw 与 PostgreSQL 容器健康，桌面及 390×844 窄屏实际页面通过。计划 60 整体未获作者认可，不作为本次施工依据。证据见[本次记录](../../audit/plan64/README.md)。

## 范围与冻结边界

移除新增全书账本前端页面、一级入口、时间线跳转、专用展示和附带技术提示；保留原有建书、大纲、章节、人物、线索、设定与朗读布局。删除前以调用者证明专用代码无其他消费者。保留人物原有状态查看、纠错、来源核验所依赖的共享组件。

底层 `story_facts`、不可变 revision、服务端范围校验、CAS、幂等、来源失效与增量索引保留，禁止删除小说数据或历史迁移。核查 AI 上下文的相关性与有效性、重复写入和冲突防护、正文变化后的来源与索引更新、自动 Skill 装载；修复有可复现证据的当前路径问题。不新增作者配置、管理页或第二套运行时，不把文学质量提升写成未经真实评测的结论。

已授权产品范围内的代码、测试、文档和长期环境安装继续执行；不启用计划 58 尚未发布的自由文本 Skill 语义补选、不变更云端授权、不调用付费模型、不提交或推送。作者本轮关于“Skill 被正确调用并改善写作结果”的指令取代此前禁用状态，专用 Agent 的项目 Skills 应启用并保持作用域隔离。当前请求不解释为恢复计划 58 或 60。

冻结公共 DTO、API、schema、迁移链与模型权威不变。删除页面的旧链接安全回到章节，不能影响普通聊天和现有页面恢复。后台维护失败不得改变正式正文；故事事实候选采用与正文采用仍遵守作者授权。

## 子代理并行施工设计

主代理是唯一集成责任人。当前 W0 范围冻结后 ready set 为 `L64-UI`、`L64-DATA-AUDIT`、`L64-SKILL-AUDIT`。

| 波次/工作包 | 目标与非目标 | 所有权与依赖 | 验收与汇合 |
| --- | --- | --- | --- |
| W0 `L64-SCOPE` SER/GATE | 按本轮指令冻结窄范围，不重设计界面 | 主代理独占本文、索引和计划60状态 | 调用图、干净工作区；已完成 |
| W1 `L64-UI` PAR/MUTEX | 删除账本前端及附带提示，保留共享事实能力和原有布局 | 主代理独占 `frontend/src/` 中实际受影响文件；后台与 Skills 只读 | 相关 Vitest、typecheck、全量前端测试和 build；浏览器桌面/窄屏 |
| W1 `L64-DATA-AUDIT` PAR | 核查有效事实读取、重复/冲突、revision 来源失效和增量索引；不更改公共接口或数据库 | 子代理只读 `backend/`、`tests/`、`scripts/` 及直接相关31/34/51/52/54文档，零写权 | 返回精确问题位置、现有保护、定向测试命令/结果和最小修复建议 |
| W1 `L64-SKILL-AUDIT` PAR | 核查当前按钮自动装载写作方法与不必要的作者操作；不启动计划58整体施工 | 子代理只读 `backend/writing_skills/`、相关生成入口、`skills/`、安装脚本及相关测试，零写权 | 返回实际启用路径、阻断点、可复现实例和定向测试结果 |
| W2 `L64-FIX` SER/GATE | 主代理复核审计后完成范围内可复现修复 | 主代理独占被证据确定的后端/Skill/测试文件，先在本文记录精确名单；接口变化重新冻结 | 定向反例和相关回归；跨领域运行全量 pytest |
| W3 `L64-VERIFY` INT/GATE/MUTEX | 集成、检查删冗余、记录实际结果 | 主代理独占本文、两个索引、证据目录 `audit/plan64/`；构建/测试资源锁归主代理 | diff/check、前后端回归、打包、隔离浏览器、未验证项和恢复说明 |

共享资源锁：同一源码、索引、锁文件、构建树、浏览器、数据库、Agent、安装树和 Git 都由主代理持有。审计代理不运行数据库写测试、全量测试、安装/卸载、不修改文件；可运行已证实无外部副作用的定向单元测试。主代理先汇合 DATA，再 SKILL，再最终全量验证。后续有写入委派时必须先冻结精确文件和测试，不能默认扩大只读授权。

W1 路由独立切片 `L64-ROUTE` PAR-C：共享页面合同已冻结为原有六页；取消账本跳转，旧 `section=ledger` 链接与缓存回到章节。该子代理唯一写权为 `frontend/src/workbench-route.ts`、`frontend/src/workbench-route.test.ts`、`frontend/src/story-timeline/contracts.ts`、`frontend/src/story-timeline/timeline-workspace.ts`、`frontend/src/story-timeline/timeline-workspace.test.ts`。主代理不写这些文件，负责工作台接线和其余测试。时间线 CAS/快照/人物卡入口保留；只删除 onOpenLedger 与专用链接合同，不改共享后端 DTO。定向 Vitest 验证；返回删除符号清单与兼容行为，之后主代理集成 typecheck。

禁止所有工作包触碰 QwenPaw 核心、旧项目 Data、真实密钥、生产小说/音频/数据卷、迁移历史、无关 TTS 功能。历史计划与验收仅补现行替代说明，不抹除原始记录。
