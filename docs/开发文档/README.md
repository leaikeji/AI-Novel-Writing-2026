## 事实标签

文档使用以下标签区分结论性质：

- **已核实事实**：由本机只读检查、官方源码、官方文档、发行页或软件包仓库核实。
- **技术推断**：根据已核实接口和运行方式推导，需在初始化后的技术尖峰中验证。
- **项目建议**：为本项目做出的可调整选择。
- **仍待验证**：没有凭证、真实数据或可运行工程时无法完成的验证。
