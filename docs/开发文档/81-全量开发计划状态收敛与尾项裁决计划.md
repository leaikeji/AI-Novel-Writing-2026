## 3. 统一终态词汇

| 终态 | 含义 | 是否继续主动任务 |
| --- | --- | --- |
| `REFERENCE` | 架构、规格、环境或历史基线；用于引用，不以“做完所有段落”为目标 | 否 |
| `CLOSED_PASS` | 计划范围已实现并有相称证据 | 否 |
| `CLOSED_WITH_LIMITS` | 执行已经结束，结果可能为 PARTIAL／HOLD／inconclusive；限制保留但不再自动续跑 | 否 |
| `SUPERSEDED` | 被后续架构、计划或范围裁决取代；历史事实保留 | 否 |
| `NOT_ADOPTED` | 方案从未获施工批准且已过期；未来需求重新立项 | 否 |
| `CONDITIONAL` | 只有凭据、真实规模或作者动作等触发条件出现后才验证或恢复窄动作 | 否，触发前不在施工队列 |
| `ACTIVE_CLOSEOUT` | 已有获准且在途的候选，需要继续发布／验收／恢复收口 | 是 |
| `PROPOSED` | 当前仍有产品价值，但只完成方案，等待作者批准 | 否，批准后转 active |

`CLOSED_WITH_LIMITS` 不把失败改写成成功；它只表示计划已产生完整、诚实的结论，剩余限制没有被授权为无限期施工。
