## 2. 工作台容器响应

浏览器复核发现，在 1024px 外层 viewport、QwenPaw 左栏和右侧助手同时展开时，宿主助手以 overlay 覆盖中栏；原实现仍按被覆盖前的容器宽度布局，导致账本只剩几十像素。

候选修复使用宿主给出的 overlay 布局状态计算实际可见宽度，并让 `.mb-workbench[data-assistant-overlay="true"]` 成为局部 inline-size container。现有 container query 因而按作者真正可见的约 318px 中栏降级为单列紧凑导航，不自动折叠或改写 QwenPaw 原生助手。

同轮浏览器还发现“查看”后 URL 深链回写会作废同一详情请求，页面停在“正在读取事实详情”。`workspace.ts` 现将 owner 对当前选中 fact 的深链回显识别为同一状态，不再 invalidate 活跃请求；新增回归证明信号不被 abort，真实页面复验详情、来源和时间线切换均恢复正常。
