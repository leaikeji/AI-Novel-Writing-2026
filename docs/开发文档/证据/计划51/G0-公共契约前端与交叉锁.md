## 2. 前端冻结契约

### 2.1 稳定 operation key 与异步隔离

- correction/revert 在“打开意图 + canonical payload fingerprint”时创建 attempt；同 payload 的网络失败、超时或未知结果重试复用 key。
- 用户修改业务 payload、切换 fact/batch、成功完成或明确放弃意图时才轮换／清除 key；不得在每次点击 submit 时重新生成。
- append、impact preview、source、workspace refresh 和 mutation 各有独立 generation + AbortController。接收 response 前同时核对 generation、novel/fact/batch、filter fingerprint 和 snapshot token。
- mutation 可能已在服务端提交时，不以本地 abort 伪装撤销；忽略迟到 UI 更新后，使用同 operation key 查询／重试并刷新当前 snapshot。
- timeline 本地 token/version 在 props、mutation 成功和普通 refresh 后同步；切换 timeline 会取消旧线请求并清空不兼容 cursor。

### 2.2 列表与可访问性

全尺寸统一使用带字段标签的记录列表：语义为 `<ul>/<li>` 或等价 list/listitem，不再声明不完整的 `table/row`。宽容器可用 CSS grid 对齐“事实／状态／来源／操作”，但不得伪装 header/cell；窄容器保持同一 DOM 阅读顺序。

筛选有可见 label；更多菜单有可读名称、Escape 和焦点返回；加载、冲突和完成使用克制的 live status。来源抽屉先渲染有界 excerpt 并定位 `<mark>`，作者显式选择后才加载完整 immutable revision。

### 2.3 容器响应

- `>=960px`：账本列表与详情双栏；
- `640–959px`：单栏列表，详情进入抽屉／面板；
- `<640px`：字段标签卡片、筛选纵向折叠、内部导航可滚动；
- 断点基于 PawApp 中栏 container，不基于外层 viewport；左右宿主栏任意组合均不得形成逐字纵排或横向溢出。

全部 7 个内部 section 都跑 shell smoke；人物、账本、时间线跑深验收。不得用自动折叠 QwenPaw 原生助手掩盖中栏失效。

### 2.4 timeline 与 deep link

- 单一活动 timeline 零配置并隐藏选择器；多 timeline 使用完整 `tablist/tab`：`aria-selected`、roving tabIndex、Arrow/Home/End 与焦点同步。
- 内部 section key 冻结为 `ledger`。deep link 至少支持 `section=ledger`、`ledger_fact`、`ledger_timeline`、`ledger_type`、`ledger_state`、`ledger_health`、`ledger_source_document`；UUID/enum 无效时忽略该字段并保留可恢复页面，不请求越权 ID。

## 3. 原生助手 context envelope

schema：`story-ledger-assistant-context/1`。白名单只含：

- novel ID、snapshot token、当前 timeline ID／显示名；
- 规范化筛选；
- summary 固定计数；
- 选中 fact 的 ID、type、实体显示标签、predicate、object_text、effective state、health、reason codes；
- source 的 document/revision ID、可见标题、坐标版本、range hash、是否当前 revision。

禁止字段：完整 revision 正文、`source_excerpt`、未筛选 details、密钥、Provider 私有配置。envelope 总长度上限 6,000 Unicode code points；超限按固定字段优先级裁剪，不把正文塞进 assistant context。
