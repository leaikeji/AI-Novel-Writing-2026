- 标题弹窗内的选区工具已 portal 到同一项目 modal focus scope；真实 DOM 中 `dialog "编辑章节标题"` 内包含 `region "章节标题选区助手"` 以及七个具有语义名称的 button。
- `Escape` 从选区工具按钮可关闭工具条；取消选区后工具条按 controller 规则关闭。
- 页面字段工具条继续挂到页面层，避免被正文滚动容器裁切。
- 真实浏览器已验证鼠标框选、操作点击、审阅跳转、逐处决定、拒绝全部、接受全部和退出；焦点态有非颜色边框。

当前 in-app Browser 的 locator `press("Enter")/press("Space")` 能聚焦按钮，但不能可靠模拟浏览器原生 click；因此没有把该控制层现象写成应用失败。原生 button 语义、单元键盘事件和实际鼠标闭环均通过。人工中文 IME 候选窗（而非 CompositionEvent 契约）仍应在发布前由使用者做一次短复核。
