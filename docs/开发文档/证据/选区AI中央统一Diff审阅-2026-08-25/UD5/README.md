## 2. 真实创作流程

安全样书：`潮声替我说晚安`，第 4 章 `退回的旧木盒`。

### 2.1 润色与差异质量

- 对 `1,067` 字正文执行真实“润色”，模型没有产生可验证的实质改动时，审阅器显示“未发现可验证的实质差异”。
- 直/弯引号及半角/全角同族引号差异不再制造大量伪修改；双引号与单引号、空白及其他标点的真实变化仍保留。
- 模型摘要不再作为权威描述直接保存；作者看到的摘要由最终不可变 Diff 重建，因此不会再出现“摘要说三处、Diff 只有两处”。
- MiniMax 两次真实请求曾返回多个候选 JSON；新增的一次隔离会话纠错重试可以自动恢复。第二次仍不合规时继续 fail closed，不猜选候选。

### 2.2 正文应用、保存、刷新与恢复

- 定点指令只执行第一句 `压 → 沉`，审阅为 1 处红/绿替换。
- 原正文长度：`1,067` 字符。
- 原正文 SHA-256：`50e8638661675e79fba021d15a102791874b9d97e48b3890917754a1532a9650`。
- 应用候选 SHA-256：`dbdc3455d4166f2224c1ccd66699de92beadda93fa53e861a6154832128327b9`。
- 接受全部后正文进入 `applied`，页面显示正在按原流程自动保存；随后保存按钮状态为“已保存”。
- 刷新页面后 `已经沉下来了` 仍存在，证明持久化完成。
- 从“生成历史”恢复第 3 次已采用正文，再次刷新后原文恢复；最终 SHA-256 与原正文完全一致，`已经沉下来了` 不存在。

### 2.3 标题纯删除、改写与撤销

- 纯删除：`退回的旧木盒 → 退回的木盒`；Diff 同时显示红色 `删除 旧` 和绿色 `应用后结果为空（删除此段，不保留文字）`。
- 接受后标题草稿确实变为 `退回的木盒`；点击“撤销 AI 修改”恢复 `退回的旧木盒`，未保存弹窗随后取消。
- 实质改写：`退回的旧木盒 → 雨夜退回的木盒`；Diff 为新增 `雨夜` 与删除 `旧`，应用后一步撤销再次恢复原标题。
- 最终页面标题仍为 `第4章 退回的旧木盒`，没有留下验收改动。

## 5. QwenPaw 公开边界

只读审计确认 QwenPaw 2.1.0 的公开 `chat.request.render/prepend/append` 可以组织消息，但公开 `ChatRequestData` 是不透明 `Record<string, unknown>`，没有可信 `origin.pluginId/kind`。因此本次没有使用私有 DOM、私有 store、启发式文本匹配或修改上游来只隐藏注入上下文。

当前合规降级保持：上下文可见、助手整栏可折叠、任务使用独立 `context_ref/session`。若上游将来提供可信消息来源或 model-only context API，再在项目适配层实现精确隐藏。
