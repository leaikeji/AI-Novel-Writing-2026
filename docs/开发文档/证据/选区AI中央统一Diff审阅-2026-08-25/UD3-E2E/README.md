## 2. 浏览器闭环

已实测：

- 正文、标题与弹窗字段框选后出现七项选区工具；一键直接创建项目任务，不复制 Clipboard、不要求切到右栏二次发送。
- 生成态保留原文；ready 后在当前字段主工作面打开统一 Diff。
- 上一处/下一处、逐处接受/拒绝、部分决定计数、拒绝全部、接受全部、退出审阅均可操作。
- 标题候选执行“接受全部 → 一步撤销”后恢复原标题；“接受一处 → 拒绝全部”后仍为原标题。
- 正文候选执行拒绝全部后退出审阅，正文未变化；无差异状态也可安全退出。
- 工作台内点击原生“新建对话”后 URL 可变为 `/chat`，但卷章树、编辑器和右侧原生助手仍在同一窗口；新会话不携带旧候选卡。
- 独立新标签页进入普通 `/chat` 时不存在章节树、小说助手壳或页面上下文，只保留 QwenPaw 原生聊天。
- 章节树搜索“雾里”只显示命中卷章，点击可跳转；卷折叠/展开、整树折叠/恢复通过。
- 助手展开/折叠通过；200% 等效 960×540 下可通过折叠助手和章节树恢复可用正文宽度。

## 3. 视觉迭代与最终三栏比例

初次同视口比较发现：当助手保存为 520px 最大宽度时，1525×1031 下中央 Diff 被压窄，工具栏换行，和获选方案存在 P1 差异。

修订后章节工作区优先保留 880px 主区；三种 density 通过继承 CSS 变量把章节树设为 286/240/220px。最终同视口实测：

- 工作台容器：1275px；
- 右侧助手：395px；
- 主工作区：880px；
- 章节树：220px；
- 中央编辑/Diff：约 660px；
- 助手为 inline，不覆盖中央区。

该比例与获选参考稿的树、中央区和原生助手分配接近；中央 Diff 仍使用项目真实标题、工具和模型结果，不冒充参考站品牌或聊天内容。
