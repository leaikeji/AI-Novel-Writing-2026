## 复查补强

- effective 模型解析会先确认 `ai-novel-writer` Agent 作用域真实存在且启用，再读取 QwenPaw effective 结果，避免 Agent 缺失时被全局模型静默掩盖。
- provider/model 只接受非空字符串；JSON `null`、数组、对象、缺失字段和空字符串都不能被转换为伪模型身份。
- 正文、情报与通用创作任务继续使用 requested/actual 双证据；前端只有收到 actual 时才显示“实际”，否则明确显示“实际未核验”。
- 创作任务幂等摘要已纳入目标字数，改变目标字数不会错误复用旧任务。
- 结构化 502/503 错误会保留后端原因以及 requested/actual 审计，不再退化为裸 HTTP 状态。
- 创建向导、章节向导和大纲向导在重新打开时恢复最近任务的模型证据。
- 章节正文采纳后的情报同步改为独立确认，不再在用户不可见的情况下继续调用模型。
- 关系网“补全历史关系”在调用前显示当前 effective 模型并要求确认；本次真实浏览器验收只打开确认框并取消，没有发起付费生成。
- 390×844 真实视口下页面宽度与视口均为 390px，无页面级横向溢出；当前确认框显示 `minimax-cn / MiniMax-M3`，与 QwenPaw Agent 和插件接口一致。
- 修复确认框等待期间误显示“正在读取关系同步状态”的文案；等待确认时保持正常状态，读取、生成和确认三个阶段不再混淆。
