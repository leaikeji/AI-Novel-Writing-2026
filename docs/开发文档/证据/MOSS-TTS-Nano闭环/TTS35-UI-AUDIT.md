# TTS35-A2-UI：长期服务真实浏览器只读审计

> 审计日期：2026-08-29（Asia/Shanghai）
> 工作包：`TTS35-A2-UI`
> 环境：`http://127.0.0.1:18088`，QwenPaw `2.1.0`，PawApp `/health` 报告版本 `0.4.0`
> 样书：`雾港失序钟（三章账本验收·20260829）`（3 章、6136 字、3 个人物）
> 结论：**不通过；当前长期服务不能作为计划 35 的 UI／播放器验收环境，也不能据此宣称 `CORE-FINAL`。**

## 1. 审计边界与方法

- 使用 Codex 内置浏览器对长期服务进行真实页面观察、DOM 可访问树检查、四个指定视口截图、控制台检查和只读 HTTP 核验。
- 请求的视口分别为 `2560×1440`、`1920×1080`、`1280×800`、`390×844`。浏览器内容区实际像素分别为 `2535×1426`、`1900/1901×1069`、`1267×792`、`386×835`，差值来自浏览器框架。
- 未点击“保存”“创建作品音色档案”“智能朗读”“删除”等会产生持久写入或真实合成的按钮；未创建、修改或删除任何小说、朗读配置、音色、音频或媒体。
- 中文输入只在“新档案名称”本地输入框中临时替换为 `顾砚舟（键盘审计，不保存）`，随后立即刷新；刷新后恢复为 `顾砚舟专属声音`，未提交网络请求。
- 使用只读 GET 核对 `/health`、`/novels/{novel_id}/narration-overview`、`/voice-presets`；未调用任何 POST、PUT、PATCH 或 DELETE。

## 2. 阻断问题

### [P0] 长期服务 UI 与已部署后端目录不一致，18 个官方音色在页面不可达

只读 API 事实：

- `/voice-presets` 返回 `moss-tts-official-preset-catalog/2.0`；
- 共 18 个音色，18 个 `selectable_now=true`，18 个 `previewable_now=true`；
- 语言覆盖 `zh-CN`、`en`、`ja-JP`。

但长期页面实际显示：

- “MOSS-TTS-Nano · 6 个中文官方预设”；
- “先创建档案，再从 6 个中文官方预设中选择声音”；
- 无“官方音色”区域，无 18 音色搜索、语言筛选、直接绑定入口；
- 直接打开 `reading_panel=voice-library` 会被当前前端路由清除参数并回退到旧“朗读总览”。

这说明长期服务正在运行的前端 bundle 未包含计划 33 已声称存在的 18 音色直用界面，或者插件安装／bundle 接线未生效。后端有 18 个目录并不能替代页面可用性验收。

证据：

- [2560×1440 旁白设置](TTS35-UI-AUDIT/2560x1440-narrator-settings.png)
- [1280×800 旁白设置](TTS35-UI-AUDIT/1280x800-narrator-settings.png)
- 页面可访问树明确出现“6 个中文官方预设”。

### [P0] 计划 35 的页面结构与能力闭环尚未部署

计划 35 冻结的五个区域为“基础朗读、官方音色、人物配音、高级调音、私人音色”。长期页面实际仍为六个旧入口：“总览、旁白、人物配音、选角规则、发音与停顿、音频与缓存”。

只读 `/narration-overview` 仍返回 `narration-capabilities/1`，没有以下三项能力：

- `character_voice_matching`
- `nano_advanced_tuning`
- `private_voice_deletion`

人物页仍要求先创建作品音色档案，且提示“所有绑定仍需作者单独保存”；没有“根据人物卡匹配官方音色并使用”一键入口，也没有高级调音实验和私人音色生命周期入口。

证据：[390×844 人物配音](TTS35-UI-AUDIT/390x844-character-voice.png)。

### [P1] 390×844 章节播放器和章末操作区被严重压缩、遮挡

窄屏章末实测：

- “章节智能朗读播放器”容器 `clientWidth=207px`，但 `scrollWidth=562px`；
- “重新生成／修改章纲／同步进展／历史”按钮可见宽度均只有约 `28px`，文字相互覆盖；
- “智能朗读”按钮可见宽度约 `42px`，在卡片最右侧仅剩狭窄橙色区域；
- 页面出现多条嵌套水平滚动条，播放器正文提示和主操作不能在当前视口完整读取或可靠点击。

这不满足“窄屏不得遮挡正文或助手”的验收口径，且会直接阻断移动端播放器使用。

证据：[390×844 播放器空态](TTS35-UI-AUDIT/390x844-player-empty.png)。

### [P1] 小说加载失败没有错误态，永久停在“正在载入作品…”

访问不存在的小说 `2c1715bf-9fb2-4abd-a047-96e4f4165df4` 时，只读 API 返回 HTTP `404`：

```json
{"detail":"novel 2c1715bf-9fb2-4abd-a047-96e4f4165df4 not found"}
```

页面等待 8 秒以上仍只显示“正在载入作品…”，没有错误信息、重试或返回入口；控制台也没有 warn/error。源页面因此无法从失败态自行恢复。

证据：[1280×800 无效小说加载态](TTS35-UI-AUDIT/1280x800-invalid-novel-loading.png)。

| 1920×1080 | 三栏可用，无页面级横向溢出；首屏只显示设置上半部 | 卡片完整，无横向溢出 | 布局通过，产品闭环不通过 |

390×844 的只读结构测量还显示：

- “作品创作流程”导航 `clientWidth=268px`、`scrollWidth=508px`；
- “朗读设置”导航 `clientWidth=234px`、`scrollWidth=494px`；
- QwenPaw 原生助手保持折叠，主内容右缘与助手之间仍有间距，**助手本身没有覆盖正文**；主要问题来自 PawApp 内容自身的固定宽度和横向溢出。

## 4. 人物配音、播放器与失败态覆盖

### 人物配音

- 可在 3 个人物间切换，服务端影响摘要、语言和声音策略可读取。
- 当前默认是“暂不配置声音”，没有一键人物卡匹配。
- 新人物声音需先创建“作品音色档案”，之后再选择、试听、锁定并单独保存；门禁数量与计划 35 的一次点击目标不一致。
- 未触发创建、锁定或保存，因此没有改写人物绑定。

### 播放器

- 未配置旁白，章节显示“本章尚未生成朗读”，只能看到空态与“智能朗读”入口。
- 为保护长期数据，本工作包未点击“智能朗读”；因此播放／暂停、前后段、进度跳播、倍速、音量、当前说话人、失败重试、Edition 身份在长期服务中均为**未验证**，不能写成通过。
- 桌面空态卡片无横向溢出；窄屏空态存在上节所述严重裁切。

### 网络与控制台

- `/health`：`status=ready`；Narration `lifecycle_status=ready`、Sidecar 可达、协议 `moss-tts-sidecar/1.1`；production worker 运行中，`reference_clone_ready=false`。
- `/narration-overview`：能力契约仍为 v1。
- `/voice-presets`：18 项均可选择、可试听，但当前页面没有对应新音色库入口。
- 浏览器记录的控制台 warn/error 均为空。
- 当前浏览器控制接口不提供逐请求 Network 面板或响应状态导出；HTTP 状态仅以同一长期服务的只读 GET 复核，未冒充完整浏览器网络时序通过。

## 5. 键盘、焦点与 IME

- DOM 可访问树中，朗读导航、人物切换、表单输入、保存按钮和播放器空态均有可识别名称；当前可见按钮未发现 TTS 专属的空 accessible name。
- 点击人物按钮或音色档案输入框后，通过当前浏览器控制接口发送 `Tab`，焦点仍停留在原控件。这个结果无法区分产品焦点陷阱与浏览器控制接口限制，因此**完整键盘遍历、焦点顺序和焦点环可见性未验证**，不能判通过或直接定性为产品缺陷。
- 中文字符串可以写入“新档案名称”输入框；刷新后恢复默认值，证明没有保存。浏览器接口不能产生 macOS 输入法候选窗和完整 `compositionstart/update/end` 流程，因此真实 IME 组合输入仍为**未验证**。

## 7. 退出门禁建议

本工作包建议 `TTS35-INT` 和 `TTS35-QA` 至少完成以下事项后重新验收：

1. 重新打包并安装当前 PawApp，记录 bundle hash，确认长期／隔离浏览器真正加载包含 18 音色库的新 bundle。
2. 页面导航改为计划 35 的五区结构，能力读取升级到 `narration-capabilities/2`。
3. 在 `390×844` 取消播放器和章末按钮的固定宽度，确保播放器 `scrollWidth <= clientWidth`、主按钮完整可见且操作区不重叠。
4. 修复 `!novel` 分支优先显示加载错误，并提供“重试／返回创作中心”，不能用无限 loading 覆盖 catch 后的错误。
5. 在隔离 QwenPaw／隔离数据库中产生至少一章可播放 Edition，再完整验证播放器控制、失败重试和 Edition 身份。
6. 使用可真实驱动 Tab 与 macOS IME composition 的工具补做键盘／焦点／IME 验收。

在上述问题修复并重新验收前，裁决应保持：`TTS35-A2-UI=FAIL`，`CORE-FINAL` 不得通过。
