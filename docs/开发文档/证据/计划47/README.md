## 4. 《雪线沉钟》真人主链复验

在新的隔离小说《雪线沉钟》上，完成官方声音选择、六人物说话人修正、重分析、人工修正继承、作者批准、Nano 真实合成、多 Edition 切换和 1.5× 播放/暂停。

| 证据 | 结果 |
| --- | --- |
| 脚本版本 | `17`，`0 blockers / 6 warnings / 16 segments` |
| 人工继承 | `6 / 16` 句段，均保留作者说话人修正 |
| 审计动作 | `reanalyze_segments 3→4`，`approve 4→5`，均为 `owner` |
| 终态 | request `ready@7`；script `approved/manual_after_review`；Edition `ready` |
| 播放 | `16/16` 句可播；1.5× 从第 2 句播放、暂停及进度恢复正常 |

本轮在真实操作中发现并修复：

1. 生成请求默认作者为 `local-owner`，而脚本审计为 `owner`，导致合法人工修正无法继承；现改为唯一常量。
2. 继承结果的请求版本在一个事务中多次跳转，触发 PostgreSQL 单调 trigger；现按“持久化脚本 → 记录动作 → 进入复核”两个严格的 `+1` 步骤执行。
3. 人工继承脚本因父版本已批准而误走自动冻结，最终拒绝作者确认；现明确识别 `manual_override` 的人工/继承归因，强制作者复核。
4. Edition 和 Manifest 短暂投影偏差会被客户端立即当成永久身份错误；现仅对该可识别短暂情形有界重读整个聚合。
5. 警告唯一时的筛选栏和播放器中的 `Edition` 术语对作者没有操作价值，已删除/改为“冻结声音”。

运行期捕获到的脚本操作错误现会以稳定 operation 和服务端堆栈写入日志，HTTP 客户端仍只获得脱敏错误。
