# 冻结评分合同

## 一、确定性硬门槛

每项记录 `pass|fail|uncertain` 和定位说明：

1. 事实边界：没有新增题面禁止的人物、设备、通道、能力或确定事实。
2. 人物知识边界：没有让视角人物凭空知道题面未提供的内容。
3. 视角：保持题目指定的第三人称限知视角。
4. 篇幅：先做 NFC 规范化，再删除全部 Unicode 空白字符，按 Unicode code point 计数；区间包含两端。
5. 必要锚点与状态变化：题目要求的锚点和变化均可在正文中定位。
6. 纯净输出：只有正文，不允许标题，也没有 Markdown/JSON/XML 包装、创作说明、评分或提示词复述。

程序只直接裁决篇幅、空输出和明确包装。锚点、禁止新增、人物知识、视角和状态变化必须保存正文定位证据后由评审者作语义裁决；关键词命中只能作为候选定位，不能自动判定通过或失败。任何语义项尚未人工确认时，样本总结果至多为 `uncertain`。

任一硬门槛明确失败，该样本不得靠主观高分抵消；仍保留并参与退化归因。

## 二、匿名质量评分

盲评者不知道候选属于A组还是B组。每项1—5分并写一句证据：

- 吸引力
- 人物可信度
- 场景推进
- 语言自然度
- 类型满足度
- 可继续修改性

悬疑专项另评1—5分：

- 线索与假设边界
- 调查行动因果
- 信息释放匹配度
- 揭示后的继续空间

每对样本还需选择 `left|right|tie|both-fail`，并说明最主要的胜负原因。

## 三、首轮研究判定

- 本轮只有4题×2次，不能套用计划22的十二题正式退出门槛。
- 候选组硬门槛不得低于基线组。
- 若候选组在至少3/4题的成对多数中获胜，且悬疑专项平均分提高、通用六维无明显退化，可建议进入正式人工盲评。
- 其他结果均保留为“需修订”或“否决”，不修改正式 Skill。
