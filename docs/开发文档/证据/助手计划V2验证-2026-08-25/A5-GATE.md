# A5-G：选区与原生发送体验门禁

- 状态：✅ 通过
- 日期：2026-08-25
- 范围：`A5-A` 至 `A5-E`；本门禁只证明选区注册、字段锚定、动态建议与失效隔离，不代表 A6 的结构化提案和写回已经完成。
- 真实宿主：QwenPaw 2.1.0，本项目 PawApp 正式安装态，目标 Agent 为“AI 小说作家”，有效模型为 `minimax-cn / MiniMax-M3`。

## 1. 已通过项

- 选区记录使用随机 UUID，保存 UTF-16 起止、方向、选中文本、完整字段 SHA-256、作品/文档/字段/上下文版本、Agent 和会话绑定。
- 标签页内存注册表默认 TTL 20 分钟、上限 50 条，超限按 FIFO 淘汰；作品切换、字段卸载、会话不匹配和过期均失效。
- 正文、标题、章纲、大纲、人物、关系、线索和设定八类受控字段均已在真实页面框选；新字段激活后旧字段工具条消失，无跨弹窗、跨字段污染。
- 鼠标/键盘事件、中文 IME composition、滚动、缩放、长文本、换行、宿主原生 Sender 焦点切换均有自动化覆盖。
- 工具条按字段/可视区域定位并避开 56px 宿主顶栏；字段外点击或字段销毁时安全收起。
- 点击“润色”等动作会展开原生助手并注册短命令建议；在原生输入框键入 `/polish` 可见 `/polish-selection · 润色选区`，选区正文不塞入命令值，而由 `context_ref` 与当前会话原子绑定。
- 当前阶段仍保留作者最后一次发送确认；没有通过私有接口自动发送。
