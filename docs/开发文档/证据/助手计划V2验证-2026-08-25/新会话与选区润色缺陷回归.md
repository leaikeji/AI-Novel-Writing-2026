## 缺陷 1：工作台内新建对话跳回主页

- 修复前：点击原生 `spark-newChat-fill` 后 URL 进入裸 `/chat`，路由状态机清除 workbench owner，章节工作台消失。
- 修复后：同一运行期有效 owner + tab-scoped owner/novel 双匹配时，`/chat/{旧 session} -> /chat` 转为 `workbench-no-session`；新 session 生成后继续绑定。fresh/direct `/chat` 的新状态机仍清理旧存储。
- 真实结果：点击新建对话后 URL 为 `/chat`，章节目录、当前正文编辑器和 QwenPaw 原生空白助手同时保留。

## 缺陷 2：选择正文后点击润色没有可执行动作

- 已核实公开契约：QwenPaw 2.1.0 的 `chat.sender` 只公开 `set` 和 `addSuggestion`，未公开命令式 send/prefill。
- 修复：点击选区动作即复制完整 slash 命令并展开原生助手；工具条与 toast 明确提示在原生助手粘贴后点击发送。复制失败时保留公开 suggestion 和手工命令。
- 边界：不操作 QwenPaw 私有 DOM/store，不自行调用第二套聊天发送器，不绕过原生流式、停止按钮和工具安全状态。
