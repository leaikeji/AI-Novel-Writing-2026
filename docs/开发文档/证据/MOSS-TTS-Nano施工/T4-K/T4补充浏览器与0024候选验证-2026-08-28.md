## 2. 真实浏览器发现与修复

补充 observer 固定检查 1920×1080／2560×1440、助手收起／展开四组合，并要求五次由作者使用 macOS 系统中文输入法产生的可信 composition 事件。真实运行在进入人工输入前依次发现三项问题：

1. 临时第二章为空白时，产品按设计显示“开始写作”引导，不挂载正文编辑器；验收夹具却等待编辑器并超时。后续临时章必须先写入项目自有测试正文，结束后按精确 ID／version 删除。observer 现将未挂载编辑器降为稳定 `SUPPLEMENT_CHAPTER_SWITCH_EDITOR_UNAVAILABLE`，不再泄漏 Playwright 通用超时。
2. 章节切换时旧播放器可能在“已看见根节点”和“读取 Edition 下拉框”之间卸载。`playerProjection()` 现对三个易失读取使用 1 秒窄超时，卸载竞态返回 `null`，由章节状态机继续判定，不再阻塞 30 秒。
3. 工作台 `replaceState` 更新 `document_id` 后会触发一次正常章节加载和一次同章节重复加载。重复加载只增加 `documentGenerationRef`，相同 document ID 的 editor surface 不会重建，最终造成 generation／lease 不一致，返回原章后朗读会话拒绝启动。新增 `canReuseActiveDocumentLoad()`：只有 document ID、editor lease 与当前 generation 三者精确一致时跳过重复加载；编辑器关闭、尚未挂载、章节不同或 generation 不同均不得复用。

所有诊断只在专用 T4 小说中创建一个明确命名的临时章节；每轮 `finally` 均返回 `SECONDARY_CHAPTER_CLEANED`。未改变 canonical 正文、Edition、Manifest、人物绑定或音频。
