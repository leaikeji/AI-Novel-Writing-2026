## 1. 本轮为什么重画

本轮先重新截取当前运行界面，再按已经变化的真实布局重做全部 TTS 页面。当前产品不再是旧稿假设的单一 PawApp 画布，而是同时包含：

```text
QwenPaw 全局导航
  + PawApp 作品/章节导航
  + PawApp 中央业务区
  + QwenPaw 原生 AI 助手
```

因此 V2 冻结以下布局原则：

- TTS 作品级设置只进入 PawApp 中央业务区；右侧原生 AI 助手保持完整可用，不承载 TTS 业务表单。
- 作品工作台在“设定”下新增“朗读”，七个朗读子页使用紧凑、可横向滚动的二级导航。
- 当前中央区宽度有限，人物、音色、规则和缓存使用分组列表与纵向卡片，不使用横向大表。
- 章节播放器只占章节编辑区底部，从章节树右侧开始、在原生 AI 助手左侧结束。
- 脚本复核改为编辑区内部的底部面板，不再使用会与原生 AI 助手冲突的第二个全高右侧抽屉。
- 句段高亮只到句段级；不设计逐字卡拉 OK 效果。

上一版目录保留为历史设计记录，但其页面骨架和脚本复核抽屉不再作为当前候选：
[页面设计评审 V1](../18-MOSS-TTS-Nano智能朗读-页面设计评审-2026-08-25/README.md)。

## 4. 与 V1 相比的关键修正

1. 所有作品工作台稿件都保留右侧原生 AI 助手，避免把设计建立在不存在的可用宽度上。
2. “朗读”稳定放在作品栏“设定”下；创作中心增加相同入口，后续路由必须恢复 `section=reading`。
3. 七个朗读子页统一为紧凑二级导航；在受限宽度下允许横向滚动，不能换行挤压页头。
4. 通用音色、选角规则、发音与缓存由矩阵/宽表改为纵向分组，桌面舒适、紧凑和受限密度可以复用同一信息架构。
5. 人物声音继续放在当前 720px 左右的编辑人物 Modal 中，不新增人物详情路由。
6. 固定播放器明确限制在 PawApp 章节编辑区内，并要求正文预留真实底部空间。
7. 脚本复核从右侧抽屉改为中央区底部面板，避免与 QwenPaw 原生助手争夺同一列。
8. 默认生成链路改为“零阻塞自动继续、异常才暂停”；不再让每章无条件多一次审批点击。

## 5. 自动识别与自动配音如何落入 V2 页面

V2 设计中的“自动配音”不是让作者逐句手工选择声音，也不是让 MOSS-TTS-Nano 自己猜人物。完整分工为：

```text
系统自动切分正文与识别说话人
  -> 自动匹配人物卡、匿名人物或通用音色
  -> 计算 warnings 与 blockers
  -> 默认策略且零阻塞：自动冻结脚本并创建 Edition
  -> 有阻塞或启用逐章复核：进入集中复核
  -> 作者清除阻塞项并一次确认继续
  -> Nano 自动生成全部可用句段音频
```

页面映射如下：

- [朗读总览](./02-朗读总览.png)：显示人物声音覆盖率、warnings/blockers、待复核章节和自动分析/生成任务。
- [人物配音](./04-朗读-人物配音.png)：展示正式人物是否使用专属声音、继承声音或尚未配置。
- [选角规则](./06-朗读-选角规则.png)：管理本地规则、人物匹配优先级、匿名人物、复核策略和可选云端智能增强。
- [脚本复核底部面板](./12-章节编辑器-朗读脚本复核底部面板.png)：只在出现阻塞或作者启用逐章复核时集中处理问题，不要求逐句打开人物卡。
- [音频与缓存](./08-朗读-音频与缓存.png)：在脚本自动/人工冻结后显示自动合成、部分就绪、失败重试和 Edition 状态。
- [章节播放](./10-章节编辑器-朗读播放与句段高亮.png)：播放自动生成的多角色音频，并按句段跟随正文。

默认本地规则会先处理明确人名、别名、说话动词、前后提示语、场景人物和对话轮次；只有用户单独授权后，系统才把不确定句段和最小上下文交给受控聊天模型辅助判断。`unknown` 不得静默套用某个角色并进入正式 Edition；只有作者显式选择临时试听时才允许使用中性备用音色。

### 5.1 终审冻结的复核策略

- `仅异常复核 / blockers_only`（默认）：用户显式发起朗读后，分析成功且 `blocker_count = 0` 时自动冻结脚本并创建 Edition；中置信度只作为可追溯提醒。
- `每章都复核 / always_review`：即使零阻塞也打开复核面板，作者确认后才生成，适合重要章节或出版前校听。
- 逐次操作允许勾选“本章生成前先让我确认”，只能临时收紧，不能静默放宽作品设置。
- “扫描全书”使用 `analyze_only`：只更新覆盖率、提醒和阻塞统计，不生成 Edition 或音频；以后真正生成时重新校验正文和设置 fingerprint。
- 低置信度、`unknown`、别名冲突、匿名身份冲突、缺失音色、非法人物/scope 和硬性发音冲突均阻断正式 Edition。
- 分析失败、模型身份不匹配或返回结构非法属于失败，不得降级为提醒后自动继续。

[脚本复核图](./12-章节编辑器-朗读脚本复核底部面板.png)代表“存在阻塞”或 `always_review` 路径；默认零阻塞路径不会打开该面板。图中“审批并生成 Edition”在实现时按路径改为“处理完成并继续生成”或“确认脚本并生成”。[选角规则图](./06-朗读-选角规则.png)实现时在本地/智能增强模式区下新增“复核策略”单选项；这是同页小幅补充，不新增页面或新的导航层级。

若旧 Edition 正在播放时打开复核面板，音频默认继续，完整播放器收为面板内/上方的紧凑播放条；不得让播放器和复核面板形成两个互相覆盖的 fixed layer。分析期间正文继续修改时，面板显示来源 revision，并提供“继续生成该快照”和“使用最新正文重新分析”。

全书流程同样按异常隔离：扫描只报告；批量生成需先确认章节范围、预计时长/磁盘和策略。零阻塞章节可继续，有问题的章节留在总览待办，不连续弹出多个面板，也不因一个 blocker 停住整本书。

实现不得只覆盖正常截图，还要覆盖下列同页状态；它们不需要新增一级页面：

| 页面/区域 | 必须实现的状态 |
|---|---|
| 总览 | 首次未初始化、模型下载/校验/预热、仅扫描完成、分析中、零阻塞自动继续、阻塞待处理、分析失败、授权撤销、磁盘不足 |
| 选角规则 | `blockers_only`、`always_review`、本地模式、智能增强未授权/已授权/撤销、规则冲突 |
| 脚本复核面板 | 加载、只看阻塞、查看全部提醒、阻塞未清零、清零可继续、来源 revision 已落后、紧凑播放器共存、保存冲突、重分析失败 |
| 音频与缓存 | queued、rendering、partial_ready、ready、单句失败、任务恢复、可安全清理/不可清理 |
| 编辑器与播放器 | 正在准备目标段、目标窗口就绪、播放缺口、离线重连、旧稿朗读、无唯一映射、更新就绪待切换 |
| 响应式布局 | 当前宿主舒适/紧凑/受限桌面宽度、移动窄屏；底部面板和播放器不得覆盖正文主操作或右侧助手 |

### 6.1 可达性终审要求

- 复核面板打开时焦点进入标题或首个阻塞项，关闭后回到触发控件；支持完整键盘遍历和可见焦点。
- 阻塞、提醒、成功和旧稿状态同时使用文字/图标，不只依赖颜色；分析与生成进度使用非打断式 live region。
- 固定播放器、段落 gutter、上下句和倍速具有可读名称与足够点击目标；正文必须预留播放器高度。
- 复核面板与紧凑播放器共存时仍保留“旧稿”状态、说话人、播放/暂停和进度的可读名称，不能让音频在不可控状态下继续播放。
- 受限宽度下句段列表和编辑表单上下堆叠；二级页签可滚动但须可被键盘访问并显示当前页。
- 截图只能证明视觉空间关系，不能证明 WCAG 合规；焦点顺序、读屏名称、对比度、缩放回流和中文输入法必须在真实实现中验证。

## 7. 自检结论

- 12 张 V2 设计图均保留当前宿主外壳、作品栏和原生助手的空间关系。
- 作品级配置与章节级播放分层，未把旁白、通用音色池或选角规则重复塞入编辑器。
- 正文和 `spoken_text` 继续隔离；发音替换不会写回小说正文。
- 正文修改后继续播放旧 Edition，不静默热切换；新音频由作者显式更新。
- 普通清缓存仅针对可重建资产，不包含上传原件、标准化参考或锁定音色版本。
- VoiceGenerator 仍标记为实验能力；阶段 0 未通过前不能作为稳定入口。
- 当前正文控件仍是原生 `textarea`；图中的句段 gutter 和可编辑高亮是目标态，实施前必须通过编辑器 ADR 与兼容性尖峰。
- 默认零阻塞自动生成、阻塞异常暂停和逐章精细复核已经在主流程、状态机、API、数据、测试与阶段工作包中保持一致。

## 8. 证据边界

- 本轮确认了 12 张设计图的布局、信息架构和状态契约，没有可运行 TTS 页面，因此不能验证真实点击、焦点、滚动、读屏、响应式回流或模型时延。
- 当前截图宽度代表桌面目标态；紧凑/受限桌面和移动窄屏必须在对应阶段产出真实浏览器证据后才能退出门禁。
- 竞品公开能力只用于确定同类产品目标，不构成复制其私有算法、声音资产或交互细节的证据。

## 9. 评审顺序

建议按以下顺序审查：

1. 先审 01–02，确认入口、作品栏位置和七个朗读子页。
2. 再审 03–08，确认作品级声音与生产治理。
3. 再审 09，确认人物卡声音流程和 VoiceGenerator 实验入口。
4. 最后审 10–12，确认边听边改、旧稿契约和脚本复核底部面板。

本目录全部图片均为视觉与交互评审稿，不代表相关 API、数据库、模型 Runtime 或前端功能已经实现；批准设计也不自动越过专项文档的阶段 0 门禁。
