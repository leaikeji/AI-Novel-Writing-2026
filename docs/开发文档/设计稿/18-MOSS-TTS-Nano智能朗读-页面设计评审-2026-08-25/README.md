## 2. 页面归并结论

- 不新增独立播放器页面；播放器固定在章节编辑器内。
- 不新增独立首次配置向导；初始化过程放在“朗读总览”。
- 不新增第二套模型选择页面；只展示 MOSS-TTS-Nano 的运行状态。
- 不新增匿名人物独立路由；常态治理放在“选角规则”，当前章节问题放在脚本复核抽屉。
- 音色来源、多候选试听、上传权利确认、云端分析授权、音色锁定、版本历史和清缓存确认复用抽屉或弹窗，不膨胀为独立页面。
- VoiceGenerator 在阶段 0 通过前只能隐藏或标记“实验性”，不能在产品稿中承诺为稳定能力。

## 3. 本轮自检结论

- 所有稿件均沿用当前亮色 PawApp 设计系统，没有重做 QwenPaw 原生外壳。
- 作品级设置与章节级播放已分层，旁白、人物音色池和选角规则没有重复塞入编辑器。
- 正文与朗读文本保持隔离；发音替换不修改小说正文。
- 正文变化后不自动热切换 Edition，旧稿继续可播，新版本必须由作者显式选择。
- 普通清缓存只处理可重建资产，不与私人音色原件或锁定音色的删除混用。
- 当前稿按 1920×1080 桌面基线设计；390–430px 窄屏适配应在本轮桌面信息架构批准后单独出响应式状态稿，避免在未定稿页面上重复返工。

## 4. 评审建议

建议按以下顺序确认：

1. 先确认入口、左侧“朗读”导航和七个子页的信息架构。
2. 再确认人物卡声音流程和“文字描述生成”是否保留为实验入口。
3. 最后确认章节编辑器中的段落跳播、旧稿提示、Edition 切换和脚本复核密度。
