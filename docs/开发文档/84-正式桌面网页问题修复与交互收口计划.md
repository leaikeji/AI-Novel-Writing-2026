## 1. 背景与结论

2026-09-14 在长期正式环境 `http://127.0.0.1:18088`、QwenPaw 2.2.1、PawApp 0.4.0 上完成一轮桌面网页交互实测。覆盖创作中心、既有作品工作台、全书搜索、大纲、人物、线索、设定、朗读、助手展开／折叠、私有库、向量设置、语音设置和回收站；实测桌面尺寸为 1920×1080 与 1366×768，未显式提交作品／正文／私有库保存，也未执行模型生成、音频生成、恢复或删除。源码复查确认：打开建书向导会通过公开API创建或复用可恢复的建书草稿，关闭时还可能保存该草稿，因此这部分不能再表述为全程只读；P84-FREEZE必须补录正式草稿基线及本次交互是否产生版本变化。

结论：当前主链可用，没有发现权威正文或作品被错误修改；建书草稿是否变化仍待P84-FREEZE按公开接口核实，不能从“没有点击保存”外推为数据库完全未写。现已确认 6 项本项目应修问题和 1 项低风险无障碍文案问题。它们应作为新的独立计划修复，不倒改计划83的`CLOSED_WITH_LIMITS`结论，也不夹带计划80、82、Agent、Skill或文学评测范围。

2026-09-15最终裁决：F84-02—F84-07已在不含入口改造的拆分候选中完成全量代码校验及正式Edge桌面矩阵；获准复用的同一草稿只保存一次，作品／草稿／私有资产／内容版本最终为`6/7/16/41`。F84-01仍缺少QwenPaw公开的首轮路由前注册／未知路由重放合同；作者接受该限制并将计划整体裁决为`CLOSED_WITH_LIMITS`，不以其余六项通过掩盖入口阻断，也不再追加高风险绕行。

### 2.1 已验证正常，不作为修复理由

- 1920×1080 与 1366×768 均无页面级横向溢出；助手展开后现有桌面 container query 能把导航改为紧凑布局。

- 本轮未发现 PawApp 浏览器错误、重复 DOM ID 或顶层交互控件无可访问名称。
- 上述结果不是完整 WCAG 合规证明，也不证明未经操作的保存、模型、音频、删除或恢复链。

### 2.2 宿主观察项，不进入本计划

- QwenPaw 侧栏存在大量未分组聊天，以及历史《槐巷早饭》聊天标题；它们是宿主聊天历史，不代表已删除小说复活。本计划不清理这些记录。
- 控制台可见`Module not found: Chat`与`Module not found: Market`宿主告警，当前未影响 PawApp 功能。本计划只留观察，不修改、覆盖或 monkey patch QwenPaw 核心；以后若产生可复现功能影响，再按公开契约单独立项。

## 3. 目标与非目标

### 3.1 目标

1. 让插件公开入口及已分配会话的创作中心 URL 成为可刷新、可直达、可恢复且不污染普通聊天的稳定公开状态。
2. 让私有库默认详情只显示作者可理解的内容，并让列表与历史使用同一“内容版本”语义。
3. 统一设定字段的作者可见名称，保留未知自定义字段。
4. 补齐安全的 Escape 关闭、焦点恢复和中文对象级无障碍名称。
5. 让常用桌面尺寸和助手挤压状态下的工作台核心入口清楚、稳定、无新增溢出。
6. 通过代码校验、公开热更新和正式桌面浏览器复验形成可恢复证据。

### 3.2 非目标

- 不修改 QwenPaw 上游核心代码、私有配置、私有数据库或未公开内部模块。
- 不设计、恢复或验收手机／平板布局，不新增手机视口 media query 或触控专属交互。
- 不清理宿主聊天历史，不恢复或重建《槐巷早饭》，不删除任何作品、正文、版本、媒体或聊天。正式键盘验收至多创建／复用一份明确登记、可继续使用的建书草稿，不得创建新作品或事后删除草稿冒充无痕。
- 不执行真实模型、TTS或embedding调用；本计划不改变这些链，也不据此宣称文学质量、模型质量或音频质量通过。
- 不进入计划80的原生助手路由、计划82的章节保存／Edition尾项，不修改Agent提示、Skill、工具开关、模型选择或Provider配置。
- 不新增数据库表、Alembic迁移、Markdown运行时依赖或第二套前端框架。

## 4. 冻结实现合同

### 4.1 创作中心 URL 合同

- 唯一可申请未知新会话的公开直达入口是`/apps/ai-novel-world-2026`；该入口先写入一次性、标签页内的会话分配权限，再进入宿主聊天路由。`?view=private-library`只作为该入口允许的一次性子视图状态传递。
- 宿主分配会话后，创作中心规范地址必须是`/chat/{sessionId}?novel_center=1`，并保留受支持的`view`参数；该完整地址可复制直达、刷新及前进／后退恢复。
- `/chat?novel_center=1`不作为公开直达入口，也不得凭根导航记录猜测任意新会话的所有权；只有刚由插件公开入口写入的一次性权限可允许宿主把它归一到一个裸会话。
- 内部“返回创作中心”沿用当前已分配的`/chat/{sessionId}`并写入规范参数，不申请未知新会话。
- 不含该参数的原生`/chat`与`/chat/{sessionId}`继续进入普通聊天。
- 地址同步使用 replace 语义，避免重复历史项、重定向环和每次渲染改写地址。
- 若公开 PawApp／`route.wrap`扩展点无法实现该合同，立即停止并登记`BLOCKED_UPSTREAM`；不得修改上游源码或已安装包绕过。

### 4.2 私有库显示与版本合同

- 现有`PrivateLibraryAssetView.version`保持资产根行 CAS／并发控制语义，不改名、不删除、不挪作显示版本。
- API 与 TypeScript DTO 新增必需字段`content_version_number`，值来自当前`PrivateAssetVersion.version_number`；详情投影和列表投影都必须返回，列表版本徽标只使用该字段。旧客户端可忽略新增响应字段，现行客户端与服务端作为同一插件包原位更新。
- 冻结投影边界：列表摘要投影只返回最多500字符的`summary`，不得加载完整`content`；详情投影返回完整`content`并可同时保留摘要。`PrivateLibraryAssetView`新增可选`content`只用于已完成详情加载的对象。
- 词汇表默认详情只显示结构化词条；原始 Markdown、转义串、内部 UUID 路径和重复内容不进入默认作者正文区。
- `content`与`summary`保持不同字段，创作中心不得再用`content`覆盖`summary`。非词汇表资产的详情显示可使用完整作者正文或其明确投影，不把内部来源标识冒充摘要。
- 编辑资料必须在`detail_loaded=true`且完整`content`存在时才开放；`assetDraftFromView()`只从完整`content`建立编辑草稿，不得回退到最多500字符的`summary`。详情缺少`content`时显示可恢复错误并禁止保存，避免静默截断长资料。
- 原始数据和来源证据不删除；需要时仍通过现有编辑／审计数据链取用。本计划只调整默认投影。
- 不做数据库迁移；若无法从当前版本关系可靠算出`content_version_number`，停止并重新裁决，不得用根`version`猜测。

### 4.3 设定字段元数据合同

- 新建`frontend/src/template-field-meta.ts`作为唯一共享映射，创作中心与工作台共同消费。
- 冻结公开导出为`TemplateFieldMeta { label: string; placeholder: string }`和`templateFieldMeta(key: string): TemplateFieldMeta`；P84-CENTER创建并测试该接口，P84-STUDIO只消费，不得另建映射。
- 已知内置键使用稳定中文标签与现有说明；未知自定义键统一显示`自定义字段（原始key）`，同时保留原 key 和原值，不静默丢弃。空key或不满足现行对象键约束的异常数据只读显示并阻止保存，不能替用户改名。
- 不改变后端字段名、保存协议、模板内容或权威数据。

### 4.4 键盘、焦点与桌面布局合同

- 建书和全书搜索弹窗在非忙碌态按 Escape 关闭，并把焦点返回触发控件。
- 建书向导冻结为`keyboard: !busy`、`closable: !busy`、`maskClosable: false`；`closeWizard()`遇到`busy`必须原地返回，不能调用`props.onClose()`。非忙碌关闭继续通过现有公开API保存可恢复草稿，失败提示和关闭语义必须明确，不得把保存失败静默当成成功。
- 全书搜索是只读请求，即使正在搜索也允许关闭；迟到响应不得重新打开弹窗、抢回焦点或覆盖下一次搜索状态。
- 1920×1080与2560×1440中，工作台核心导航及“返回创作中心”在初始状态可发现且无需猜测存在第二段滚动；1366×768助手展开时保留紧凑桌面布局、键盘可达及无横向溢出。
- 允许内容区滚动，不以隐藏导航、覆盖编辑器或缩小到不可点击来满足首屏要求。全尺寸只允许一个可聚焦的“返回创作中心”控件：常规桌面固定在左栏滚动区之外，容器宽度不超过760px的紧凑桌面态进入可见的粘性导航／标题区；不得继续使用`display:none`隐藏，也不得复制出两个同时可聚焦的按钮。
- 图标按钮使用“动作＋对象”的中文标签，例如“复制亮点简介”“编辑故事主线”；可见 tooltip 与辅助技术名称一致。
