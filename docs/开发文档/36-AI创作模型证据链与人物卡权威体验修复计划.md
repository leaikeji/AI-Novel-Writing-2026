# AI 创作模型证据链与人物卡权威体验修复计划

状态：**2026-08-29 已实现并安装验收；计划 35 的 TTS 精确迁移头兼容问题待其独立修复。** 本文对应用户批准的“35 号”方案；由于工作区已有另一窗口创建的 35 号 TTS 文档，本文件顺延为 36 号，避免覆盖并行任务。

计划日期：2026-08-29（Asia/Shanghai）

## 1. 冻结目标

本计划分两阶段交付：P0 先恢复全部 AI 创作入口，P1 再统一“大纲人物草案 → 稳定人物根 → 时间线人物实例 → StoryFact 投影 → TTS 声音绑定”的人物体验。

- QwenPaw public usage 完整且身份一致时记录 `verified_from_provider_usage`。
- public usage 完全未公开、但调用前后公开 effective model 一致时记录 `not_exposed`，允许形成候选；actual provider/model 必须保持空。
- usage 畸形、身份错配、调用中模型变化或 postflight 失败时记录 `rejected`，禁止采用。
- 删除 QwenPaw 私有 usage buffer 依赖，不修改 QwenPaw 上游。
- 大纲人物保持轻量草案；正式人物卡统一编辑人物根与所选时间线实例；成长状态只读自 StoryFact 投影。
- 人物卡保留完整声音页签，但只组合现有 TTS 组件和 API，不建设第二套声音数据。
- 不重建向量、不修改向量维度、不触发向量云端调用。

本计划在模型任务证据语义上修订计划 19 的“缺少 actual 即失败”规则；`follow-agent-effective` 唯一生产路径和禁止静默模型回退仍保持不变。人物权威继续遵守计划 31 与 ADR-0007。

## 2. 公共契约与数据变更

- 新增 `ModelExecutionEvidenceV2`，状态为 `verified_from_provider_usage / not_exposed / rejected`，保存 preflight/postflight effective identity、可选 reported actual、usage 状态、request ID、Token、时延和原因；`private_usage_buffer_used` 恒为 false。
- `creative_generation_jobs`、`chapter_generation_jobs`、`intelligence_proposals` 增加可空 `model_evidence_json`；旧任务不回填、不改写。
- 新增 `ContextBudgetV2`、`ContextBudgetResultV2`、`WritingContextSnapshotV2`；调用前只记录 requested/budget model，不伪造 actual。V1 只读兼容。
- 新增类型化 `OutlineCharacterDraftV2` 和 `CharacterInstanceProfileV2.age_at_story_start_note`。新草案不按姓名自动关联；同名冲突返回 `character_link_required`。
- 新增只读 `GET /novels/{novel_id}/characters/{character_id}/workspace` 和 `GET /novels/{novel_id}/characters/{character_id}/archive-impact`；普通读取不得写数据库。

## 3. 施工波次

1. W0：冻结本文与 ADR-0009，保护其他窗口脏文件，重新发现迁移 head。
2. W1：唯一迁移 Owner 增加模型证据列；并行完成模型证据核心、Context V2 和人物只读工作区。
3. W2：主代理串行接入所有正文模型调用、采用门禁和失败诊断，删除私有 usage fallback。
4. W3：P0 自动化、安装、重启和合成人物生成门禁。
5. W4：类型化人物草案、实例 Profile V2、正式人物卡四页签和同名关联流程。
6. W5：串行汇合工作台入口，删除旧人物表单和时间线重复实例表单。
7. W6：全量测试、三视口、TTS/向量非回归和最终裁决。

## 5. 验收

- usage 缺失且 pre/post 一致时，人物生成产生 `not_exposed` 候选，actual 字段为空；畸形、错配和模型切换均拒绝。
- 大纲、正文、审稿、选区、人物补全、关系同步和情报提取使用同一证据规则。
- fresh novel 人物草案零额外步骤；同名角色必须显式关联；正式化创建稳定根和默认实例。
- 单线隐藏实例复杂度；多线必须明确实例；成长状态只读 StoryFact；年龄不足时返回区间或未知。
- 人物卡和朗读页共用声音权威；GET/workspace/context/search 零写入；旧重复 UI 无调用者后删除。
- 后端全量 pytest、前端 test/typecheck/build、Compose、打包、`git diff --check` 全部通过；浏览器覆盖 1920×1080、2560×1440、390×844。

长期数据库迁移前必须仓库外备份。真实正文模型调用、Git 提交和推送不包含在本次代码施工授权内。

## 6. 实施与退出记录（2026-08-29）

- 已删除正文 Agent 对 QwenPaw 私有 usage buffer 的生产依赖；所有生产 `ctx.chat()` 入口统一执行公开 preflight、Agent 调用、公开 postflight、可选 public usage 核验。
- `not_exposed` 可形成作者候选且 actual 字段保持空；畸形、错配、调用中切换和 postflight 失败均拒绝。
- 新迁移 `20260829_0033` 从 `0032` 线性增加三张任务表的 `model_evidence_json`，长期库已在仓库外备份后升级到该 head。
- 大纲人物草案使用 V2 字段和稳定 `draft_key`；同名正式人物不再自动合并，必须显式关联。
- 人物正式化创建或补全稳定人物根、主线默认实例及实例 Profile V2；正式人物卡统一基础资料、本线档案、成长状态和声音入口。
- 多时间线人物卡首次打开先要求作者明确选择时间线和人物版本，不按最近值或姓名猜测；单时间线仍零额外步骤。
- 安装后在 1920×1080、2560×1440、390×844 验收人物卡，无页面横向溢出；四页签和共用声音组件均可访问。
- 未执行真实正文模型调用、向量模型调用、向量重建或实验库重建。

最终测试事实与截图见 `audit/plan36-character-workspace/`。全量测试中仅剩计划 35 所属的三个过时源码断言：两个测试把 Alembic head 写死为 `0032`，一个前端测试要求已被统一人物卡取代的旧弹窗源码 token。另发现计划 35 的 TTS 生产门禁把数据库版本写死为“恰好 `0032`”，因此在合法后续 head `0033` 上报告 `TTS_DATABASE_SCHEMA_OUTDATED`；该缺口不在计划 36 中修改，必须由计划 35 的独立 worktree 修正为“所需迁移已位于当前线性祖先链”语义。
