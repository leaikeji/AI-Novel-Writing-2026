## 1. 结论

本计划只补齐两个已经存在但尚未发布到产品层的本地能力：

1. `Qwen3-TTS-12Hz-1.7B-VoiceDesign`：根据文字描述生成一段合成音色锚点；
2. `Qwen3-TTS-12Hz-1.7B-Base`：根据合成音色锚点或作者有权使用的参考录音，生成可长期复用的人物声音。

正式章节不直接依赖 VoiceDesign 的临时 `provider_voice_id`。VoiceDesign 只负责第一次生成参考音频；作者确认前，再由 Base 使用该参考音频合成另一段试听。最终锁定的声音始终以 Base 参考复刻方式参与章节朗读，因此服务重启、模型卸载和后续章节生成都不依赖进程内临时状态。

本计划不恢复 MOSS、Nano、VoiceGenerator、旧 `voice_preparation_commands`、人物批量自动生成或 24 槽通用池，也不在每章开始时重新设计音色。

新增统一语言规则：无论使用官方音色、文字设计音色还是上传录音复刻，产品内生成、试听和章节朗读都只使用普通话。页面不提供粤语、四川话、东北话等方言或地域口音选项，后端不接受方言指令，worker 固定使用 `zh-CN`／普通话执行。正文中原本存在的方言词句不由 TTS 改写，但只能按普通话朗读。

- Mac 本地运行时已有 CustomVoice、Base、VoiceDesign 三种模型角色和串行加载锁；三者已分别通过真实中文生成与 0 swap 验证。
- 本地运行时已有 `/v1/voices/clone` 与 `/v1/voices/design`，PawApp Provider 也已有 `clone_voice`、`design_voice` 和模型身份校验。

- `narration.voice_preview` 后台任务种类已由计划 62 改为 `qwen-tts` 资源类，没有随 MOSS 专用任务一起删除。

- 正式 worker 曾只领取 `narration.segment_render`；V0.6 已同时处理 `narration.voice_preview`。
- VoiceDesign 的进程内临时设计 ID 不再作为耐久身份；V0.6 保存普通话参考 WAV，并统一由 Base 使用参考资产生成试听和章节音频。
- 计划 75 发布时保留了官方 speaker 的原始语言分组；V0.6 已把官方、设计和上传路径统一限制为普通话。

## 3. 产品流程

### 3.1 入口

复用朗读页现有“私人音色”区域，不新增独立模型管理页。作者先选择或创建一个作品内音色档案，再选择以下来源之一：

- **文字设计音色**：填写人物音色描述和试听文本；语言固定为普通话，不提供选择器；
- **上传参考录音**：上传 WAV／FLAC、填写参考文本和现有权利声明。

音色档案可在锁定后通过既有“人物配音”能力绑定给一个人物。人物入口可以预选人物，但不复制第二套音色工作台。

### 3.2 文字设计音色

1. 作者填写性别／年龄感、声线、语速和情绪等自由描述；不得填写方言、地域口音或非普通话指令，系统不强制复杂参数表。
2. VoiceDesign 按固定普通话锚点文本、描述和 seed 生成候选参考 WAV。
3. 系统把候选 WAV 保存为该候选版本的不可变 `reference_asset`；不把临时设计 ID当作耐久身份。
4. Base 使用该参考 WAV 和对应锚点文本，合成作者填写的另一段试听文本。
5. 作者播放 Base 试听并明确确认质量后，锁定声音版本；拒绝或重新生成只创建新候选，不覆盖旧版本。
6. 后续章节只调用 Base 参考复刻；VoiceDesign 不再参与该声音的日常合成。

### 3.3 上传参考录音

1. 沿用现有 WAV／FLAC、大小、哈希、转码和权利校验；只处理作者自有、获授权或可合法克隆的普通话声音。
2. 作者确认参考录音为普通话，系统保存规范化参考 WAV 与准确的普通话参考文本；明显为方言或非中文的样本不得进入锁定状态。
3. Base 生成试听；作者播放并确认后锁定。
4. 后续章节持续使用同一参考资产，不重复提取或上传。

### 3.4 章节行为

- “一键朗读本章／全书”继续只识别说话人并解析已锁定声音。
- 新人物没有声音时继续显示 `B_VOICE_MISSING`，并给出“前往人物配音”的明确入口；不自动调用 VoiceDesign。
- 新锁定或切换人物声音只影响随后显式新建／更新的 Edition；历史 Edition 与已有音频保持不变。
- 官方音色、设计音色和上传复刻音色的试听与章节请求都固定为 `zh-CN`；人物籍贯、性格、台词用词或模型建议不得自动切换方言。

### 3.5 失败句段的最小收口

- 保留现有“音频质量失败最多允许一次作者手动重试”边界；同音色、同参数再次失败后立即成为终态，不再显示可点击的重复重试入口。
- 重试完成状态同时以后台任务和失败句段投影为准，不再只等待 Manifest revision。受影响句段全部变为 `ready` 或明确终态后，页面一次性更新计数、按钮和解释。
- 连续播放遇到 `failed/cancelled` 终态句段时，播放器明确提示“第 N 句音频失败，已跳过”，随后继续播放下一个 `ready` 句段；仍在 `pending/queued/rendering` 的句段继续等待恢复，不把尚在生成的缺口误判为终态并跳过。
- 失败详情提供“更换普通话旁白音色并更新朗读”入口。更换声音必须由作者明确操作并创建／切换新 Edition，不在同一 Edition 内偷偷混入另一种声音。
- 页面重新获得焦点、重新打开失败详情或后台任务结束时，执行一次有界权威投影刷新；稳定终态后停止轮询，不恢复整页闪烁。

## 4. 最小技术设计

### 4.1 不新增业务表

复用现有结构：

- `voice_profiles`：作品内音色档案；
- `voice_profile_versions`：上传或设计产生的不可变候选／锁定版本；
- `voice_previews`：Base 试听状态和结果；
- `media_assets`：耐久参考 WAV 与有期限试听 WAV；
- `background_jobs`：`narration.voice_preview` 的排队、租约、重试和崩溃恢复；
- `voice_rights_records/events`：上传来源的授权证据，以及合成设计音色的来源声明；
- `character_voice_bindings`：作者确认后的既有人物绑定。

不得重新建立计划 62 已删除的 MOSS／VoiceGenerator 命令表。

### 4.2 唯一前向迁移

基于施工时唯一 Alembic head 新建一个 revision，不修改历史迁移。迁移只做：

1. 允许 `source_type=generated` 使用新的稳定来源 `qwen_synthetic_design`；
2. 约束生成音色在 `preview_ready/locked` 时必须具备耐久 `reference_asset_id`；排队中的 draft 可暂时为空；
3. 校验上传／生成音色最终都以 `voice_kind=reference_clone` 进入章节生产；
4. 更新声音版本、试听任务、媒体和人物绑定的数据库闭包；
5. 保持现有官方 9 音色、旁白设置、人物绑定、Edition、render 和媒体行完全不变。

迁移不新增表，不修改小说正文，不回填或自动生成任何声音。

### 4.3 Provider 中立应用服务

新增一个窄的 `QwenVoiceProductService` 实现现有 `VoiceProductPort`：

- HTTP 请求只负责校验、创建候选与排队，模型调用不占用数据库长事务；
- `narration.voice_preview` worker 对上传版本只执行 Base 试听；
- 对设计版本先执行 VoiceDesign、发布参考 WAV，再切换到 Base 生成最终试听；
- 每次外部调用前后都核对 novel/profile/version/job、内容哈希、模型身份和租约 fence；
- API 只接受普通话语言值，拒绝方言／地域口音字段和明确的方言设计指令；worker 再次断言 `zh-CN`，不能仅依赖前端隐藏选项；
- 失败只更新候选／试听状态，不改变当前已锁定声音和人物绑定；
- 重试复用已成功发布且哈希一致的参考资产，不重复收费、不产生重复媒体。

### 4.4 本地运行时

- 继续只允许一个模型角色常驻；设计任务按 `VoiceDesign → 卸载 → Base` 串行执行。
- 正式章节只使用 `Base` 或 `CustomVoice`，并统一传入 `zh-CN`／普通话；不使用进程内 `_voice_roles` 作为耐久声音事实。
- 模型路径、revision、制品 SHA、实际模型身份继续按现有 Provider 契约校验。
- 取消、超时或进程重启后由后台任务租约恢复，不把半成品标记为可用。

### 4.5 音频质量证据

- `audio_validation_json` 继续使用现有 JSON 字段，不新增表或列；对 `SHORT_CHINESE_DURATION_IMPLAUSIBLE` 增加不含正文的有界证据：实际时长、允许上限、参与计算的字符数和策略版本。
- 质量门禁仍在转码和媒体发布前执行；失败 WAV 不保存、不发布，已有音频和媒体摘要不变。
- 先用真实普通话短句复核 Serena 和至少两个其他官方音色，再决定是否需要校准时长策略；没有客观时长证据不得放宽全局阈值。
- 同参数第二次失败是停止信号，不再用无限重试掩盖确定性模型问题。恢复方式优先为作者选择另一款已通过普通话门禁的音色并更新 Edition。

### 4.6 API 与页面契约

在现有命名空间内增加最少接口：

- `POST /voice-profiles/{profile_id}/versions/designed`：创建 `generated → reference_clone` 设计候选；请求固定包含 `expected_profile_version`、有界 `description`、`language=zh-CN` 和可选 seed，返回 `VoiceProfileVersionResource`。随后复用现有 preview 接口提交另一段试听文本并排队；
- 现有 `POST /voice-profiles/{profile_id}/versions/uploaded`：从 HOLD 开放为真实 Base 复刻候选；
- 现有 `POST /voice-profiles/{profile_id}/previews`、`GET /voice-previews/{id}`、锁定接口继续复用；
- `voice_design`、`reference_clone` 只有在 schema、VoiceProductPort、worker、媒体与对应模型身份全部就绪时才 actionable。

页面只增加“文字设计音色”来源卡及一个简短描述框、普通话固定标识、试听文本、生成／取消按钮，不提供语言或方言选择器。官方音色页统一显示“普通话”，并只提供普通话试听。每个候选只局部更新，不刷新整页，不影响章节播放器。

失败收口不增加新接口：继续复用失败句段 GET／重试 API、现有 Manifest 和后台任务状态；前端只修正终态判定、权威刷新与播放跳过行为。

W0 冻结裁决：产品唯一 TTS 语言值为 `zh-CN`；显式方言、地域口音或外语设计词返回 `VOICE_LANGUAGE_UNSUPPORTED`。设计描述只在候选尚未产出参考资产时暂存于现有 `parameters_json`，VoiceDesign 成功发布耐久参考 WAV 后立即移除明文，只保留摘要、策略版本、参考资产和模型身份。Preview 任务只保存既有有界试听文本，终态后继续按当前规则清除。

## 5. 明确非目标

- 不做每章自动设计、每个人物静默生成或批量一键造声；
- 不恢复 24 槽池、自动选角计划、旧 MOSS 数据表或 VoiceGenerator 名称；
- 不新增第二套任务队列、数据库、音色市场、波形编辑器或复杂参数面板；
- 本计划不接入阿里云声音设计，也不执行云端计费调用；本地闭环稳定后，云端设计音频可在后续小计划中作为同一 Base 参考资产来源；
- 不修改 QwenPaw 上游核心，不让模型输出直接修改人物卡或正文；
- 不自动删除候选参考音频、历史声音版本或已有朗读。
- 不提供外语、方言、地域口音或按人物籍贯自动切换发音；以后若要开放，必须另立计划并由作者重新批准。
- 不静默给单句切换音色、不把终态失败伪装为成功、不发布未通过质量校验的 WAV，也不为了消除红色提示直接放宽全局时长阈值。

## 7. 验收门禁

### 7.1 自动化

- 本地运行时：VoiceDesign、Base、模型切换、取消、错误、身份漂移和进程重启；
- 后端：上传／设计候选、幂等重试、CAS、权利、媒体发布、worker 租约、失败零污染、锁定和人物绑定；
- 后端语言规则：官方／设计／上传三条路径只接受 `zh-CN`，非普通话语言值、方言字段及明确方言设计指令都返回稳定业务错误；
- 质量证据：短中文时长失败记录实际时长、允许上限、字符数和策略版本，不保存正文或失败 WAV；
- 前端：两种私人来源、官方音色、字段校验、普通话固定标识、无方言入口、局部进度、取消／重试、试听播放、质量确认和冲突恢复；
- 失败收口：worker 在 30 秒边界前后结束都能刷新为真实终态；成功项消失、失败项禁用，按钮计数与后端一致；播放只跳过终态失败，不跳过生成中缺口；
- 数据库：现有 head 升级、新约束、四角色、整书删除与声音媒体闭包；
- 全量：`.venv/bin/python -m pytest`、`pnpm typecheck`、`pnpm test`、`pnpm build`、插件打包和 `git diff --check`。

### 7.2 真实本地模型

1. 用 VoiceDesign 生成一个测试人物候选，确认实际模型精确为冻结的 1.7B VoiceDesign；
2. 同一任务卸载 VoiceDesign 并由 Base 合成不同文本试听，核对 WAV、非静音、模型 identity 和参考哈希；
3. 作者确认后绑定测试人物，生成至少两个句段；重启本地 TTS 服务后再次生成不同句段，音色仍可用；
4. 上传一段获授权测试录音，完成 Base 试听、确认、绑定和章节生成；
5. 取消、断连、磁盘不足、模型身份不符和 worker 崩溃均不得创建锁定版本或改变既有绑定；
6. 全程确认三个模型不同时常驻，16 GiB 机器不发生 swap；真实音频和参考录音不进入 Git。
7. 对全部可选官方音色逐一生成普通话固定样句；不能稳定输出普通话的音色不得进入可选目录。设计音色和上传复刻音色也必须通过普通话试听后才能锁定。
8. 用截图中的三类短句形状复测 Serena 和至少两个其他普通话官方音色，记录实际时长与门限；若仍失败，页面在终态后不再显示可重试，并能越过失败句继续播放后续 ready 音频。

### 7.3 桌面与发布

- 仅验收桌面 Web、桌面缩放和宿主侧栏挤压；不新增手机端门禁；
- 私人音色页可完成两条闭环，状态只局部刷新，章节已生成音频可继续播放；
- 失败详情的数量、可重试按钮和后端权威投影一致；当前三句终态不能继续提交同参数重试；

- “现有官方 9 音色保持”只适用于数据不删除；可选目录以普通话真实试听为门禁，未通过者保留历史数据但不允许新选用；

- 未完成真实重启后章节生成，不得宣称 Base／VoiceDesign 产品闭环已可用。

## 8. 风险与恢复

- **音色漂移**：VoiceDesign 结果只作参考锚点；正式输出固定走 Base，锁定后不重设计。
- **冷加载较慢**：页面明确显示“正在加载声音设计模型／正在切换复刻模型”，不让多个模型常驻掩盖等待。
- **任务中断**：数据库任务和媒体哈希作为恢复事实；重试复用已发布参考资产，半成品保持不可用。
- **声音权利**：上传路径继续要求明确授权；合成设计路径要求确认“未刻意模仿可识别真人”，两类来源不得混用权利证据。
- **数据回退**：发布前保存数据库 dump 和旧插件树。若新生成音色已被绑定，不执行破坏性 downgrade；恢复使用同批 dump＋旧安装树，不删除模型、正文或媒体卷。

## 9. 完成标准

同时满足以下条件才算完成：

1. 私人音色页真实开放“文字设计”和“上传参考录音”；
2. 两条路径都经过 Base 的真实试听和作者确认后才能锁定；
3. 设计音色在本地服务重启后仍能用于新章节，不依赖临时设计 ID；
4. 人物绑定、章节更新和历史 Edition 保护通过；
5. 没有恢复任何 MOSS／Nano／VoiceGenerator／24 槽残留；
6. 官方、设计、上传复刻、试听和章节生成全部固定普通话，页面无方言入口，后端能拒绝绕过请求；
7. 失败重试完成后页面不会停留在旧投影；连续播放能明确跳过终态失败并继续下一段，生成中缺口仍等待；
8. 短中文音频失败具备足够但不泄露正文的诊断证据，质量门禁没有被无证据放宽；
9. 自动化、迁移、隔离、真实模型和桌面浏览器门禁全部通过；
10. 正式部署、Git 提交和 push 均只在作者分别明确授权后执行。
