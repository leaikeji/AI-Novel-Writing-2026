MVP-0（阶段 1–5）合计：**35–54 个 Codex 有效开发小时**；阶段 6 的真实测试约 **2–4 小时**。阶段 7–8 不计入当前承诺。

## 阶段闸门

1. 阶段一未获用户批准，不创建 Git、工程骨架、Compose 文件或依赖锁。
2. 阶段二兼容尖峰未通过，不开始大规模 UI 或数据实现，也不通过 monkey patch 绕开公共接口。
3. 阶段三并发与恢复测试未通过，不把自动保存接入真实正文。
4. 阶段五只开放只读 Agent 工具；未证明小说会话隔离时，连只读小说工具也不能启用。
5. 阶段六以前不出现计划确认、候选、Diff、接受/拒绝或 AI 直接写入能力。
6. 阶段六测试后若没有用户明确批准，阶段七和阶段八保持未立项。

## 2026-08-23 执行结果

- 阶段三：完成 PostgreSQL 18.6、pgvector 0.8.6、SQLAlchemy/Alembic、最小账本、CAS 与迁移往返测试。
- 阶段四：按用户“编辑器暂缓”决定采用 Markdown `textarea`，完成作品库、卷章、自动保存、检查点、历史恢复和 IndexedDB 崩溃恢复；没有实施 Monaco/TipTap/预览器。
- 阶段五：完成 QwenPaw 原生聊天同屏、六个可迭代 Skills 和三个只读工具；没有复制聊天组件。
- 阶段六：真实创建并保留“MVP验收样书”，完成刷新持久、revision、CAS 409、停止/恢复数据库和工具读取验收。QwenPaw 尚无 active model，因此没有向外部模型发送验收正文，也没有宣称 Skill 生成质量通过。

详细证据见[阶段 3–6 实现与验收记录](./14-阶段3至6实现与验收.md)。
