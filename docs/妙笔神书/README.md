# 妙笔神书实测记录

本目录记录 2026-08-22—2026-08-23 对妙笔神书创作端的实机拆解，目标范围为：

1. 创作中心 → 私有库。
2. 创建新小说 → 长篇小说 → 男频 → 思路 → 模板 → 命名 → 封面 → 完成。
3. 创建成功 → 立即创建大纲 → 章节目标 → 背景 → 角色 → 情节 → 亮点 → 完成。
4. 创作工作台 → 章节、大纲、角色与关系网、线索、设定与伏笔管理。
5. 全站写作能力地图、短篇九步建书、自定义模板和智能拆书。
6. 长篇章节正文生成、版本、情报回写、保存和删除闭环。
7. 正文版本恢复、多标签冲突、离线草稿，以及私有资产 A/B、输入快照和 AI 智选。
8. 用真实长篇《封存区没有明天》复核文风、卷章、关系、线索、设定和正文工作流的生态有效性。
9. 以第 4 章《复写纸底层》完成真实章纲、私有文风候选、人工修订、正式保存、情报拒绝和伏笔推进闭环。
10. 以第 5 章《从未出生的人》复核角色硬约束、内容风控失败、人工改稿后的情报失效、生成历史缺稿、审稿上下文和真实五章导出。

> 方法修正：早期唯一短语、极短正文和批次编号只作为结构探针，不再代表真实作者体验。当前站内对象已自然化，后续创作质量结论以《封存区没有明天》的连续剧情为准，详见 [13](./13-真实小说创作基线与生态有效性修正.md)。
