## 二、正文编辑生产力入口

### 2.1 可见编辑器结构

正文区是一个裸 `contenteditable`，可见操作只有：

- 返回列表。
- 删除。
- 复制。
- 保存。
- 重新生成。
- 修改章纲。
- 同步进展。
- 历史。
- 情报。

实测没有看到：

- 本章查找或替换。
- 全书搜索、结果列表或跳转。
- 撤销/重做工具栏。
- 格式工具栏。
- 快捷键说明或帮助入口。
- 保存状态、保存时间或同步失败状态。

页面中可见搜索输入为 0，可见文本输入为 0，`aria-keyshortcuts` 为 0。这里只能下结论“没有可见产品入口或无障碍快捷键声明”；不能据此断言操作系统级编辑快捷键全部失效。

### 2.2 “复制”是正文复制，不是复制章节

- 空正文点击“复制”，弹出“暂无内容可复制”。
- 非空第 2 章点击“复制”，弹出“复制成功！”。
- 章节列表没有“复制章节/创建副本”。

因此顶部“复制”只把正文写入剪贴板，不会复制标题、章纲、情报或章节实体。产品文案应写“复制正文”，避免与复制章节混淆。

## 三、新建、命名、连续创作与分卷

### 3.1 新建章节

章节列表点击“新建章节”先打开六步 AI 章纲向导。若只想手写：

```text
新建章节
  -> 我已有正文，点击直接填写
  -> 使用提示：仅限自己写正文
  -> 确定
  -> 创建稳定章节 ID 的空章节壳
```

第 2 章 ID 为 `573629`，第 3 章 ID 为 `573647`。创建后标题为“未命名章节”，正文仍处于空态；还要再次点击“我已有正文，点击直接填写”才显示编辑区。

编辑器内没有“新建下一章”“保存并新建下一章”或上一章/下一章导航。因此连续写作必须保存、返回列表、再打开新建流程。

### 3.2 章节重命名

章节标题右侧铅笔打开“编辑章节标题”：

- 输入框预填当前纯标题，不含“第 N 章”。
- `maxlength=20`。
- 实时显示“当前：N/20”。
- 标题保存和正文保存完全独立。
- 保存成功后出现提示，路径和标题立即更新。

章节列表没有行内重命名入口，必须先进入章节编辑器。

### 3.3 分卷创建与显示顺序

“新增分卷”只有名称输入、取消、确定；输入框没有可见最大长度提示，也没有 HTML `maxlength`。创建成功使用浏览器原生 alert。

本轮先创建 `R4导出卷`，再创建 `R4第二卷`。新卷显示在旧卷上方，即界面默认按创建时间倒序排列。没有拖拽手柄、上移/下移或分卷排序入口。

### 3.4 加入、移出和跨卷移动

未分卷章节提供“+ 添加到分卷”，弹窗列出全部分卷和各自章数；点击目标卷后立即移动，并用原生 alert 反馈。

章节已经在卷内时，即使作品有两个卷，页面只提供“移出”，没有“移动到其他分卷”。跨卷移动因此要执行：

```text
从当前卷移出
  -> 章节回到未分卷区
  -> 再次“添加到分卷”
  -> 选择目标卷
```

这是两次独立写操作，中间会出现暂时未分卷状态；页面没有原子移动命令，也没有批量移动。

### 3.5 没有批量操作或真实重排

章节列表可见：

- 复选框 0。
- `draggable=true` 元素 0。
- 批量工具栏 0。
- 位置编号编辑框 0。

列表顶部的 `↑/↓` 只是当前标签页的正序/倒序查看开关：同卷两章在 `↑` 时显示第 1→2 章，在 `↓` 时显示第 2→1 章。新标签仍回到默认 `↓`，所以它不是章节真实排序，也不保存作者偏好。

## 四、自动保存与保存状态

在第 2 章输入两段 36 个非换行字符后等待 12 秒：

- 当前编辑器显示“章节字数 36 字”。
- 页面没有出现保存中、已保存或本地草稿状态。
- 同时新开同一章节，仍显示 0 字和“暂无章节内容”。

因此至少可以确认：输入后 12 秒内没有把工作稿耐久保存到服务器。结合 [R2 刷新/关闭丢稿](./09-版本恢复多标签与离线恢复实测.md)，当前实现依赖显式“保存”，没有可见的耐久自动保存闭环。

点击“保存”时：

- 没有分卷则直接进入不可撤销同步确认。
- 已存在分卷则先弹“选择分卷”；可选某卷或“不选分卷”，之后才进入同一确认。
- 确认文案称角色记忆和最新进展会同步且不可撤销，即使本章是纯手写、没有任何情报。
- 保存成功只显示一次性提示；提示消失后没有最后保存时间或 revision 标识。

正文保存和章节移动仍被绑定，且反馈同时混用站内弹窗和浏览器原生 alert。

## 五、三个字数口径的精确反例（历史探针）

### 5.1 第 2 章两段正文

保存后的 DOM：

```html
R4-章节A第一段。查找词：铜铃。替换词测试：铜铃。<br><br>R4-章节A第二段。
```

| 口径 | 结果 |
| --- | ---: |
| `textContent.length` / 编辑器“章节字数” | 36 |
| `innerText.length` | 38 |
| 章节列表 | 38 |

两个 `<br>` 在编辑器计数中被排除，在列表计数中被计入。

### 5.2 第 3 章单段正文

正文可见字符为 20，编辑器显示 20；章节列表显示 21。页面没有说明多出的 1 个字符来自尾部换行、序列化还是服务端计数规则。

### 5.3 作品总计

作品卡显示 59 字，恰好等于列表的 38 + 21，而不是编辑器的 36 + 20。也就是说：

```text
编辑器口径：56
章节列表/作品口径：59
```

作者看到的“写了多少字”会随所在页面变化；这不是生成服务诊断差异，而是同一手写正文在三个 UI 层的直接不一致。

## 六、TXT 全书导出

### 6.1 操作与文件

点击“下载全书”没有格式选择、范围选择、预览或页面反馈，直接生成：

- 文件名：`黑盐回声实验_全书.txt`；重复下载由浏览器增加 `(1)`、`(2)`。
- 编码：UTF-8，无 BOM。
- 本轮文件大小：732 bytes。
- 页头：书名、总章节数、导出时间。
- 目录：三章标题。
- 正文：用等号分隔每章。

### 6.2 空章处理

第 1 章正式正文为空，但导出仍包含：

- 目录中的“第1章 回声”。
- 正文区的第 1 章标题和空内容块。

因此空章不会被过滤，也没有导出前警告或“跳过空章”选项。

### 6.3 分卷丢失

导出时网站中的真实结构为：

```text
R4导出卷：第 1、2 章
R4第二卷：第 3 章
```

TXT 中完全没有 `R4导出卷`、`R4第二卷` 或任何卷边界，只按章节号输出第 1→2→3 章。分卷结构因此无法从导出文件恢复。

### 6.4 显示排序不影响导出

在列表切换到倒序显示后再次导出，目录和正文仍固定为第 1→2→3 章。可确认 `↑/↓` 只是视图排序，不改作品真实顺序；导出也不会把当前视图顺序误当正式顺序。

### 6.5 缺失项

当前写作页面没有看到：

- Markdown、DOCX、EPUB 等格式。
- 按卷、按章节或选中范围导出。
- 是否包含空章、章纲、设定或情报的选项。
- 导出版本/revision 和内容哈希。
- 全书导入、TXT 导入或 Markdown 导入。

所以不能进行“导出后再导入并保持章节边界”的闭环测试；应明确记为功能缺失，而不是臆造流程。

## 七、结论

| 能力 | 实测结果 |
| --- | --- |
| 本章/全书查找替换 | 无可见入口 |
| 正文复制 | 有；仅复制正文，不复制章节实体 |
| 章节重命名 | 有；编辑器内完成，最多 20 字 |
| 连续新建 | 无；必须返回列表重新走流程 |
| 章节升降序查看 | 有；标签页本地视图状态 |
| 真实章节重排 | 无入口 |
| 批量选择/移动 | 无入口 |
| 跨卷移动 | 只能先移出再添加，两次写操作 |
| 自动保存 | 12 秒内未服务端保存，无可见状态 |
| 字数统计 | 编辑器、列表和作品共三种结果 |
| TXT 导出 | 有；读取正式正文、章节号正序；真实五章仍丢失分卷 |
| 导入 | 无可见入口 |

## 八、对本项目的强制约束

1. 本章和全书搜索使用同一索引，结果显示作品、卷、章、命中片段和稳定跳转；替换先预览 Diff，再按本章/选中/全书应用。
2. “复制正文”“复制章节”“从本章新建副本”使用不同动词和权限，不能共用一个模糊的“复制”。
3. 提供上一章、下一章、保存并新建下一章；连续创作不强迫返回列表。
4. 章节真实排序和正/倒序浏览分离；视图排序不得改变 position_key，重排必须有显式保存和乐观锁。
5. 跨卷移动使用一次原子命令；批量移动先展示目标、数量和最终顺序，不能要求逐章“移出再加入”。
6. 正文按防抖写入本地耐久草稿，并展示保存中、本地已保存、云端已保存、冲突、失败和时间；12 秒无反馈不可接受。
7. 工作稿保存不选择分卷、不同步角色/线路/伏笔；移动、检查点和情报采用是独立命令。
8. 编辑器、章节树、作品卡、目标统计和导出共享同一个可见字符计数器；换行规则必须文档化并有跨层测试。
9. 全书导出必须按权威 position_key，保留卷名、章名、空章策略和 UTF-8 编码；支持导出前预览和范围选择。
10. TXT/Markdown 导出包含可选的稳定边界标记或清单文件，保证本工具自身重新导入时能恢复卷章结构。
11. 导出固定到明确 revision 集合，并记录 manifest、每章哈希和失败项；不能在导出过程中混入新保存的一半章节。
12. 空章默认显式提示，可选择包含或跳过；不允许静默丢弃，也不允许作者直到打开文件才发现空块。
