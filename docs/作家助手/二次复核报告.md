## 本轮新增的 UI 实测证据

### 作品库

- 新建菜单：私密作品、阅文作品、分组。
- 作品筛选：全部作品、私密作品、阅文作品、只看分组。
- 本地导入：Word/TXT、拖拽、选择文件。
- 软件导入：橙瓜码字可选，大神码字禁用；选项包括书架书籍、大纲、文档列表、随笔灵感、字体、设置。
- 作品菜单：私密作品设置、书封管理、发布平台设置、移入分组、置顶、隐藏、回收站。
- 回收站：剩余清除天数、恢复到、永久删除。
- 投稿阅文：Word/TXT、6000–10 万字、示例、选择文件和新建作品入口。

### 短剧

- 新建剧本：剧本名称、来源、合作协议；来源为 IP 改编或原创剧本。
- 原著书单：作者/书名搜索，男女频、字数、完结、热门和改编状态筛选。
- 结果表：书名、作者、分类、状态、字数、改编状态、分页、作品详情和去改编入口。
- 作品详情会在 App 新标签内打开原著站页面；未触发改编动作。

### 模板

- 列表分类：整套、总纲、细纲、开头。
- 模板详情：大纲、角色、设定，导图视图、缩放、分享、应用于新建书籍。
- 模板投稿：笔名、类型、适合分类、标题、内容、字数和活动规则；未提交。

## 仍然存在的客观边界

- 当前账号没有覆盖所有签约状态、阅文作品状态、短剧状态和灰度开关。
- 学堂、社区、任务、商品、邀请奖励、AI 模型/次数等是在线动态数据。
- 不执行发布、删除、兑换等最终动作，就不能把成功后的所有状态写成已实测。
- 因此“不能有错”的可操作标准是：已看到什么就只写什么；没看到的单列候选，不用推测补齐。
