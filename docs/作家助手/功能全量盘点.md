# 作家助手 5.19.0 功能候选全量盘点

> 注意：本文件是细粒度候选库，不是“334 项都已由当前界面实测”的结论。它同时收录 UI、安装包、在线和条件式线索。下一轮范围讨论请以[功能主清单（复核版）](./功能主清单-复核版.md)为准；仅有“包”证据的条目必须再次验证，不能直接进入 1:1 复刻范围。

> 快照日期：2026-08-14。本文是“原 App 可能具备什么”的细粒度证据库，不是网站需求文档。活动、权益、审核规则、配额、商品、模型和在线工作台会随服务端变化。

## 标记说明

| 标记 | 含义 |
|---|---|
| `UI` | 已在本机界面中实际看到 |
| `包` | 由本机安装包的路由、组件名或界面标签交叉确认 |
| `在线` | App 中嵌入的阅文在线服务 |
| `条件` | 依赖账号、作品类型、签约状态、操作系统或灰度配置 |

“已确认的行为”列名沿用第一次整理，实际应按“证据”列理解：有 `UI` 才是当前界面实测，仅有 `包` 时只是行为线索。“依赖”列是下一轮判断能否自建的依据：`本地/自建` 表示可由我们自行实现；`阅文` 表示原功能依赖阅文账号、数据或私有服务；`AI` 表示需要模型/内容服务；`桌面` 表示浏览器不能原样照搬。

## 17. 网站复刻时不能混为一谈的边界

### 可较完整自建的核心

作品/卷/章管理、编辑器、自动保存、历史版本、双栏、查找替换、排版、主题、字数统计、计划、大纲、角色、设定、便签、知识库、导入导出、通用账号与消息。

### 需要自建复杂后端的能力

多端同步与冲突、实时拼字、好友/社区、任务与虚拟资产、AI/RAG、内容校对、图片生成、在线课程、通知、搜索、文件存储、审核工作流。

### 原 App 有，但不能默认直接复用的阅文能力

阅文登录身份、编辑直投、平台发布、VIP/订阅/稿酬、读者纠错、审核/解禁、作品数据、原著版权库、阅创学堂内容、神助社区、墨水/阅读币、客服/编辑系统。若做独立网站，需要替换为自有规则和数据；若要真实接入阅文，则必须取得官方接口和业务授权。

### 桌面专属、Web 需改造的能力

桌面托盘便签、全局老板键、本机软件数据库迁移、系统字体安装、原生自动更新、跨 App 多窗口、localhost/WebSocket 手机直连。网站可提供近似体验，但不是原样复制。

### 高风险或必须单独确认的功能

发布/投稿、永久删除、批量替换、历史恢复、虚拟资产扣除、抽奖、闭关惩罚、内容上传 AI、读者/好友隐私、日志上传、内容审核与未成年人/版权合规。
