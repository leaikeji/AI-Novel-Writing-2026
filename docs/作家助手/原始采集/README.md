# 原始采集说明

## 证据等级

- `UI`：在本机 5.19.0 版本中实际看见并核实的界面或交互入口。
- `安装包`：由本机安装包的元数据、页面路由、组件名或界面字符串交叉确认；没有执行可能修改数据的动作。
- `在线`：App 内嵌的阅文在线页面。内容、活动、权益、价格、次数、AI 模型和审核规则会随服务端变化。
- `条件式`：只在特定账号、签约状态、作品类型、系统配置或灰度开关下出现。

功能盘点中的“确认”不等于后续网站可以直接复用阅文服务；它只说明原 App 存在相应产品能力。

二次复核后新增约束：只有 `UI` 证据可以进入“当前版本已确认”主表；仅有`安装包`证据的内容统一作为候选，不能与 UI 实测并列下结论。详见上级目录的`功能主清单-复核版.md`和`二次复核报告.md`。

## 采集边界

本次操作以只读为原则。没有执行发布、投稿、交换墨水、抽奖、生成 AI 内容、上传图片、加入拼字房、创建拼字房、进入闭关室、删除、永久恢复或账号设置修改。

以下入口仅核对了界面/安装包线索，没有触发其核心动作：

- 校对：可能上传章节内容做智能检测；
- 语音输入：可能申请麦克风权限，或通过手机与电脑局域网连接；
- 发布/投稿/预审：会改变平台作品状态；
- AI 画师、情节灵感、妙笔：会消耗次数、墨水或将上下文发送到在线服务；
- 墨水兑换、幸运蛋、邀请奖励：会改变账号权益或资产。

## 隐私与版权处理

- 没有把当前作品正文、邀请码、好友二维码、站内消息正文或用户身份信息写入整理文档。
- 编辑器总览截图是用户指定目录中的本地原始证据，可能包含当时屏幕上可见的作品内容；对应的文本树文件已去除正文。
- 阅创学堂和神助社区只保存页面截图，没有保存整页文章/帖子文本树。
- 安装包只在临时目录中做只读解包以核对路由与界面标签；未将源码、专有图片或字体复制到项目文档。
