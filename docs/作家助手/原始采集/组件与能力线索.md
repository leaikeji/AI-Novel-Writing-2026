# 组件与能力线索（只读归纳）

本文件记录从本机 5.19.0 安装包的文件名、路由和界面字符串得到的功能线索。它只能证明安装包内存在相关实现或文案旁证，不等于当前账号界面已经开放，也不等于规则仍然有效；不能单独作为 1:1 复刻范围。

## 编辑与写作

- `ToolBar`：字体、背景、撤销/重做、一键排版、插入、语音输入、全屏、闭关室、查找替换、取名、AI 画师、历史、发布/投稿。
- `SideChapterPanel` / `chapter`：卷、章节、草稿、作品相关、搜索、筛选和层级树。
- `findReplace`：当前章/全书查找替换。
- `localHistory` / `diff` / `htmldiff`：本地与云端历史、差异对比、恢复。
- `ConflictDialog` / `syncStore`：本地与云端冲突、离线保存、同步、备份。
- `darkRoom`：字数/时间目标、失败惩罚、完成出关。
- `voiceInputStore` / `voiceInputUtil`：手机扫码、同 Wi-Fi、WebSocket 增量输入。
- `wordStatusStore` / `WriteData`：本次码字、码字时间、速率、空闲时间。

## 创作资料

- `outlineStore`：总纲、章纲、模板、思维导图、逻辑图、时间轴。
- `RoleStore` / `RoleCardStore` / `RoleTableGrouped`：角色卡、分类、属性、头像、别名、表格视图。
- `setStore`：设定分类与条目。
- `noteStore` / `inspirationBench` / `inspirationPopup`：灵感便签、桌面工作台和悬浮窗。
- `Knowledge`：独立知识库/个人资料库在线窗口。
- `ContinueWriting` / `AIRequest` / `useAssistWrite`：情节灵感、流式生成、评价、次数/墨水、RAG 状态。
- `AIDrawing`：AI 画师/文生图。

## 校对与协作

- `readerCorrectRequest`：读者在阅读 App 标注的错别字回流。
- 校对组件界面线索：错别字、病句、语法、风险段落、自定义词库、忽略词、全部修改、纠错 Pro 评价、移动端预览。
- `SpellGame` / `homeDetailStore`：拼字房计字、房间状态、倒计时、排行。
- `Friends`：好友、申请、排名、隐私、分享名片和召回。

## 作品库与导入

- 本地 Word/TXT 导入，单文件上限和章节标题识别。
- 软件迁移组件线索：橙瓜码字、百灵创作、大神码字。二次 UI 复核中只看到橙瓜可选、大神禁用，未看到百灵入口。
- 当前 UI 明确的迁移项为书架书籍、大纲、文档列表、随笔灵感、字体和设置；人物、设定、章纲、热键等属于安装包候选。
- 作品类型：私密作品、阅文作品、投稿作品、短剧。
- 管理线索：分组、排序、置顶、隐藏、回收站、恢复、永久删除。
- 封面线索：智能书封、书封管理、自制/自定义封面、裁剪与上传配额。

## 在线与增长

- `InkShop`、`DecorateCenter`、`Friends`、`MessageNotify`。
- 任务/签到、墨水、阅读币兑换、邀请卡、装扮、昵称身份。
- 作品数据、稿酬/订阅、评论、作家咨询、学堂、社区均存在内嵌在线页。

## 原生桌面能力

- 多窗口及“还原到侧边栏”；大纲、角色、设定、章节、妙笔、知识库可独立窗口。
- 桌面托盘快速记录灵感；便签可悬浮并跨屏移动。
- 系统文件选择、拖拽导入、字体安装、图片另存、自动更新、网络诊断、日志上传。
- URL Scheme `authorwrite://`。
