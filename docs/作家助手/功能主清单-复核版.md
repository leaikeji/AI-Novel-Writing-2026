# 作家助手 5.19.0 功能主清单（复核版）

这份清单是下一轮讨论“保留 / 删除 / 简化 / 延后 / 新增”的唯一主基线。它只描述 2026-08-14 在本机 macOS「作家助手」5.19.0、当前账号与当前服务端配置下能够复核到的产品能力。

旧的[功能全量盘点](./功能全量盘点.md)保留为细粒度候选库，其中混有安装包线索和条件分支，不能直接当作已经实测的功能清单。

## 证据口径

| 等级 | 含义 | 能否当作当前已确认功能 |
|---|---|---|
| A：界面实测 | 当前版本中实际看到页面、菜单、表单或状态；必要时只打开到最终提交前 | 可以，但只确认已看到的范围 |
| B：安装包候选 | 路由、组件名或界面字符串明确存在，但当前账号/界面没有完整打开 | 不可以；下一步只能作为候选讨论 |
| C：在线/条件 | 已看到在线入口或条件分支，但内容、规则、账号权限或灰度配置会变 | 只能确认入口和本次快照 |
| X：未确认 | 仅有弱线索、含义不唯一，或此前写得过度 | 不进入复刻基线 |

“入口已见”不等于已验证提交、发布、兑换、删除、AI 生成或其他会改变账号数据的最终动作。

## X. 已从主基线剔除的过度表述

- “角色文本/卡片双模式”：只确认当前文本模式，其他模式未展开。
- “角色 CSV 导出”：只有安装包线索，不能写成已实测。
- “历史普通/里程碑版本”和“版本容量”：更接近内部实现/限制，不作为独立用户功能。
- “请假/缺勤”：当前统计页只确认“存稿折算假期”。
- “妙笔对话设置”：未确认独立设置面板。
- “百灵创作可直接导入”：当前软件导入界面没有显示，只能留作候选。
