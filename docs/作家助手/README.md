## 当前结论

「作家助手」并不只是一个编辑器，而是由五类能力组合而成：

1. 本地优先的长篇写作、章节管理、历史版本、离线同步；
2. 大纲、角色、设定、灵感、校对、拼字、AI 等创作辅助；
3. 阅文投稿、发布、审核、作品数据、收入和互动工作台；
4. 好友、社区、学堂、任务、墨水、邀请和装扮等增长体系；
5. macOS/Electron 专属能力，如桌面托盘便签、多窗口、软件导入、更新与故障诊断。

因此“一比一做成网站”至少包含三种不同难度的复刻：纯前端交互、需要自建后端的数据能力、依赖阅文私有账号/API/审核体系的外部能力。后续范围讨论必须把这三类分开。
